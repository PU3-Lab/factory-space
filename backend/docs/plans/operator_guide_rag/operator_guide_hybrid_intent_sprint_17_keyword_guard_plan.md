# Sprint 17. 제작 질문 키워드 방어선 보강 계획

## 목표

통신탑처럼 제작 후 배치되는 설치물에 대해, 플레이어가 자연어로 제작법을 물어도 제작 레시피 질문으로 분류되게 한다.

이 Sprint는 LLM 보조 분류기를 도입하기 전의 1차 방어선이다.

## 포함 범위

- `question_classifier.py`의 제작 질문 키워드 보강
- `지어`, `짓`, `건설`, `건축`, `조립`, `레시피`, `만들기`, `만드는` 표현 처리
- 통신탑 제작 질문 스모크 테스트 추가 또는 유지
- CSV 근거가 있는 경우 답변에 제작 레시피 핵심 정보가 포함되는지 검증

## 제외 범위

- LLM intent classifier 구현
- 새로운 CSV schema 추가
- Unreal UI 수정
- RAG ingestion 로직 수정

## 대표 테스트 질문

```text
통신탑 어떻게 만들어?
통신탑 어떻게 지어야 해?
통신탑은 어떻게 짓는 거야?
통신탑 건설 재료 알려줘
통신탑 조립 방법 알려줘
통신탑 레시피 알려줘
```

## 기대 결과

최종 답변 또는 근거에는 아래 정보가 포함되어야 한다.

```text
통신탑 제작 공정
합성기
철근 20
구리선 20
주석판 20
```

## 완료 기준

- 외부 LLM 없이 smoke test가 통과한다.
- 통신탑 제작 질문이 `unknown_question`으로 떨어지지 않는다.
- 기존 장비 설명, 자원 설명, 문제 해결 질문 테스트를 깨지 않는다.
