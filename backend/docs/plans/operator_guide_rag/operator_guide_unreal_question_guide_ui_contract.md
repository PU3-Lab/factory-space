# operator_guide 질문 가이드 Unreal UI 협의안

## 목적

operator_guide NPC 대화 UI에서 플레이어가 질문할 수 있는 범위와 예시를 자연스럽게 안내한다.

질문 가이드는 모든 답변 앞에 자동으로 붙는 안내문이 아니다. 별도 UI 탭으로 제공하고, 플레이어가 필요할 때 확인할 수 있게 한다.

UI 톤은 **튜토리얼 퀘스트 안내판 70% + NPC 수첩 30%**로 확정한다.

질문 가이드 탭이 숨겨지지 않도록 `질문하기` 탭 안에도 작은 진입점인 "질문 예시 보기" 버튼 또는 링크를 둔다.

## 추천 UI 구조

```text
NPC 대화 UI

[질문하기] [질문 가이드]

질문하기 탭
- 플레이어 자유 질문 입력
- NPC 답변 표시
- sources / confidence / recommended_actions 표시
- 작은 진입점: "질문 예시 보기"

질문 가이드 탭
- 질문 가능 범위 안내
- 질문 카테고리
- 예시 질문 버튼 또는 리스트
- 더 정확히 질문하는 팁
```

## UI 톤 결정

```text
선택 방향:
튜토리얼 퀘스트 안내판 70% + NPC 수첩 30%

의도:
- 플레이어가 게임 안에서 자연스럽게 도움을 받는 느낌
- 너무 딱딱한 FAQ/매뉴얼처럼 보이지 않게 하기
- NPC가 "이런 식으로 물어보면 내가 도와줄 수 있어"라고 알려주는 톤
```

## 최종 UX 방향

```text
기본 구조:
[질문하기] [질문 가이드] 탭을 나눈다.

보완:
질문하기 탭 안에도 작은 "질문 예시 보기" 버튼/링크를 둔다.

추천 흐름:
NPC에게 상호작용
-> 기본은 [질문하기] 탭
-> 입력창 근처에 "질문 예시 보기" 표시
-> 플레이어가 클릭하면 [질문 가이드] 탭으로 이동
-> 예시 질문 버튼을 누르면 [질문하기] 탭으로 돌아오고 입력창에 질문 자동 입력
-> 플레이어가 필요하면 수정 후 전송
```

## 질문 가이드 탭을 눌렀을 때 플레이어에게 보이는 화면

질문 가이드 탭은 NPC가 새 답변을 말하는 채팅 말풍선이 아니라, NPC 대화 UI 안에 열리는 도움말 패널이다.

```text
┌────────────────────────────────────────┐
│ NPC 도움말                              │
│ [질문하기] [질문 가이드]                 │
├────────────────────────────────────────┤
│ 이렇게 물어볼 수 있어요                  │
│                                        │
│ 장비, 자원, 제작법, 전력, 물류,          │
│ 고장 원인을 중심으로 물어보면             │
│ 공장 매뉴얼을 찾아서 도와드릴게요.        │
│                                        │
│ 장비                                    │
│ [제련기는 뭐야?]                         │
│ [컨베이어는 어디에 써?]                   │
│                                        │
│ 제작법                                  │
│ [기어는 어떻게 만들어?]                   │
│ [철괴를 만들려면 어떤 장비가 필요해?]      │
│                                        │
│ 문제 해결                               │
│ [컨베이어가 멈췄는데 뭘 확인해야 해?]     │
│ [철괴가 안 만들어져. 왜 그래?]            │
│                                        │
│ 더 정확히 물어보는 팁                    │
│ - 장비 이름을 같이 말하면 더 정확해요.    │
│ - "안 돼"보다 상황을 구체적으로 말해줘요. │
│ - 선택한 장비가 있으면 상태도 볼 수 있어요.│
└────────────────────────────────────────┘
```

표시 원칙:

```text
- 질문 가이드 탭은 플레이어가 직접 눌렀을 때만 열린다.
- 관련 질문에 대한 답변 앞에 자동으로 붙지 않는다.
- 범위 밖 질문이나 애매한 질문에서는 "질문 가이드 탭을 확인해 주세요" 정도로만 안내한다.
- 예시 질문은 텍스트보다 버튼 형태를 우선 추천한다.
```

## 예시 질문 버튼 동작

예시 질문 버튼을 눌렀을 때는 바로 전송보다 입력창에 채우는 방식을 우선 추천한다.

```text
1. 플레이어가 [기어는 어떻게 만들어?] 버튼 클릭
2. UI가 [질문하기] 탭으로 이동
3. 질문 입력창에 "기어는 어떻게 만들어?" 자동 입력
4. 플레이어가 필요하면 문장을 수정
5. 플레이어가 전송 버튼을 눌러 질문
```

추천 이유:

```text
- 플레이어가 예시 질문을 자기 상황에 맞게 수정할 수 있다.
- 실수로 버튼을 눌렀을 때 바로 질문이 전송되지 않는다.
- 튜토리얼 NPC 톤과 잘 맞는다.
```

추가 옵션:

```text
빠른 질문 모드가 필요하면 버튼 클릭 즉시 전송도 가능하다.
다만 기본값은 "입력창에 채우기"로 둔다.
```


## 질문하기 탭 동작

관련 질문이면 질문 가이드를 끼워 넣지 않고 바로 답한다.

```text
플레이어:
기어는 어떻게 만들어?

NPC:
기어 제작에는 매뉴얼 기준으로 필요한 입력 자원과 제작 장비가 필요해요.
관련 레시피를 기준으로 필요한 재료와 장비를 확인해 안내할게요.
```

현재 상태가 필요한 질문이면 백엔드가 Current Game State Tool을 사용한다.

```text
플레이어:
철괴가 안 만들어져. 왜 그래?

NPC:
현재 선택한 장비 상태를 함께 확인해볼게요.
전력, 입력 자원, 출력 저장 공간, 레시피 설정을 순서대로 점검하는 것이 좋아요.
```

## 범위 밖 질문 처리

범위 밖 질문은 길게 설명하지 않고, 짧게 범위를 안내한 뒤 질문 가이드 탭으로 유도한다.

```text
플레이어:
오늘 날씨 어때?

NPC:
그 질문은 내 공장 매뉴얼 범위 밖이에요.
나는 장비, 자원, 제작법, 전력, 물류, 고장 원인에 대해 도와줄 수 있어요.
예시는 질문 가이드 탭에서 확인해 주세요.
```

응답 JSON 예시:

```json
{
  "final_answer": "그 질문은 내 공장 매뉴얼 범위 밖이에요. 장비, 자원, 제작법, 전력, 물류, 고장 원인에 대해 도와줄 수 있어요. 예시는 질문 가이드 탭에서 확인해 주세요.",
  "question_type": "out_of_scope",
  "sources": [],
  "confidence": "low",
  "recommended_actions": [
    {
      "type": "open_question_guide_tab",
      "label": "질문 가이드 보기"
    }
  ],
  "metadata": {
    "selectedAgent": "operator_guide",
    "selectedLeafAgent": "unknown_question",
    "guideSuggested": true
  }
}
```

## 애매한 질문 처리

질문이 너무 짧거나 애매하면 바로 가이드 전체를 출력하지 않고, 짧은 재질문과 예시를 준다.

```text
플레이어:
안 돼.

NPC:
어떤 장비나 제작이 안 되는지 알려주면 더 정확히 확인할 수 있어요.
예를 들면 "철괴가 안 만들어져" 또는 "컨베이어가 멈췄어"처럼 물어봐 주세요.
```

## Unreal 쪽에서 필요한 액션 타입

```text
open_question_guide_tab
- 질문 가이드 탭을 연다.
- 질문하기 탭의 "질문 예시 보기" 버튼도 이 액션과 동일하게 동작한다.

use_example_question
- 예시 질문을 질문 입력창에 채운다.
- payload 예시: `{ "question": "기어는 어떻게 만들어?" }`

show_source_detail
- 답변 근거 문서를 펼쳐 보여준다.
```

## 최종 협의 포인트

- 질문 가이드는 자동 출력이 아니라 별도 탭으로 둔다.
- UI 톤은 튜토리얼 퀘스트 안내판 70% + NPC 수첩 30%로 잡는다.
- 질문하기 탭에는 작은 "질문 예시 보기" 진입점을 둔다.
- 관련 질문은 바로 답변한다.
- 범위 밖 질문은 짧게 안내하고 `open_question_guide_tab` 액션을 내려준다.
- 예시 질문은 버튼으로 제공하고, 기본 동작은 질문 입력창에 채우기로 한다.
- 백엔드는 질문 가이드 데이터를 JSON으로 제공하고, Unreal은 이를 UI로 렌더링한다.
