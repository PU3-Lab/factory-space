# Request

## 작성 규칙
- 이 문서는 팀원이 수행한 작업이나 다른 팀원에게 요청할 작업을 기록한다.
- 여러 팀원이 각자 자신의 AI를 사용해 이 파일을 수정할 수 있다.
- 새 작업을 추가할 때는 기존 번호 다음 숫자를 사용해 `### n. 요청 요약` 형식으로 작성한다.
- `요청 요약`에는 요청 내용을 한눈에 알 수 있도록 짧게 적는다.
- 각 작업에는 아래 항목을 유지한다: `작성자`, `작성일`, `요청 대상`, `요청 내용`, `참고 사항`
- 기존 작업 내용은 지우지 말고, 새 요청은 새 번호로 추가한다.
- 작성일은 `YYYY-MM-DD` 형식으로 적는다.
