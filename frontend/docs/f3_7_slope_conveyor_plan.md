## 2. 최소 변경 설계 (벨트 침습 = 상태 1개 + 수식 2지점)

```
[그리드 — 우리 소유]                          [벨트 — SSR/Chan 소유, 최소 침습]
게이트: 균일 ∥ 경사(㊆)                       TArray<float> PathCellLocalZs (신규 멤버, 기본 빈)
경로 셀별 SurfaceZ 수집(GetFoundationSurfaceZ  OJJ_SetPathCellLocalZs(Zs) (신규 세터 — OJJ_ 접두로
— F1-a 셀별 저장으로 데이터 기성)               침습 표식, 기존 SetPath 시그니처/호출처 무변경, ㊃)
→ 시작 셀 기준 로컬화(㊇) → 세터 주입          GetPathCellLocalZ(i): 빈 배열 → 0.0f
                                              #2: Z항에 + GetPathCellLocalZ(i)  (평면 +0 = 항등)
                                              #3: pitch = atan2(ΔZ, CellSize),
                                                  길이 ×√(1+(ΔZ/CellSize)²)   (평면 0/1 = 항등)
```

- **세그먼트(㊄)**: 경사 직선 = 기존 직선 메시를 pitch로 기울이고 빗변 길이만큼 스케일 — 에셋 0.
  현 회전 합성(`YawQuat * RollQuat` :405)에 PitchQuat 1개 삽입. 셀 i의 ΔZ = Z(i+1)−Z(i)
  (마지막 셀은 이전 델타 — VisualDirection :378과 같은 규약).
- **코너(㊅)**: 경사 구간 방향 전환은 그리드 게이트가 거부 → 코너 셀은 항상 ΔZ=0 → 코너 메시
  배치 코드 무변경(벨트 침습 추가 절감).
- **아이템**: #2에 Z만 들어가면 Lerp/외삽 자동(#4, #5). `ItemVisualZOffset`은 경사면 위에서도
  로컬 +Z 유지(시각 수용 — 프로토).
- **포트 Z 정합**: 경로 양 끝 셀 = 머신 점유 셀이고 그 SurfaceZ가 곧 머신 건설면 — 끝 셀 Z를
  그대로 쓰면 양 끝 머신과 자동 정합(신규 규칙 0).

## 3. 회귀 0 보장 — 최우선 설계 기준 (항목 4)

기존 평면 컨베이어(팀 전체 사용)는 **구조적으로 3겹** 보호:

1. **게이트 분기**: 균일 검사 성공(기존 경로 전부) → 기존 코드 경로 그대로, 경사 검사는 균일
   **실패 시에만** 진입(`균일 ∥ 경사`) — 평면 경로는 신규 코드 도달 자체가 0.
2. **주입 부재**: 균일 경로엔 Z 배열을 주입하지 않음 → `PathCellLocalZs` 빈 배열 → 벨트 수식
   +0.0f / pitch 0 / 스케일 ×1 — 수학 항등.
3. **커밋 순서(㊈)**: 벨트 인프라(주입 경로 없음 — 죽은 코드)를 먼저, 그리드 게이트 개방을
   마지막에 — 어느 중간 커밋에서도 기존 동작 보존.

"한 비트도"의 엄밀성: +0.0f 가산과 pitch-0 쿼터니언 합성은 값 항등이지만 연산 자체는 추가됨.
이마저 차단하려면 빈 배열 시 기존 수식으로 분기(코드 복제) — ㊉에서 결정.

## 4. 그리드 측 우리 작업 (항목 3)

- **게이트 완화**(:343): 균일 실패 시 경사 검사 — ① 인접 경로 셀 간 |ΔSurfaceZ| ≤ 45uu(램프
  행간 최대와 동일 상수) ② 방향 전환(코너) 셀은 ΔZ=0 ③ 전 셀 SurfaceZ 유효(램프 중간 행의
  비격자 값 허용이 곧 이 게이트의 존재 이유 — 단일 높이 규칙의 램프 경로 예외).
- **셀별 Z 산출**: `GetFoundationSurfaceZ` 셀별 조회(F1-a부터 셀별 저장 — 데이터 기성), 비커버
  셀은 지형/평면(현 균일 규칙과 동일 소스). 시작 셀 기준 로컬 델타 배열로 변환(㊇) 후 주입.
- **액터 Z**(:2574): 균일 성공 → 기존 단일값(무변경), 경사 → 시작 셀 SurfaceZ.
- **호버 프리뷰**: 셀 타일 Z는 `OJJ_GetCellVisualBaseZ`가 이미 셀별 — 무변경 예상.

## 7. 검증 계획 (구현 승인 후)

1. **평면 회귀(최우선)**: 기존 컨베이어 전수 — 지형/Foundation 위, 코너 포함 경로, 아이템

3. 다단 램프(Δ2~3단) 등반 + 평면→램프→평면 혼합 한 라인.
4. 경사 구간 코너 시도 → 거부 사유 확인(㊅). 45 초과 단차 직접 걸침 → 여전히 거부(기존 규칙).
