# 2026-06-24 리뷰 01 — #352 땅↔평지 Foundation 직접 컨베이어 금지 (높이차 관통)

## 변경 요약

컨베이어가 땅(맨땅) 위 머신과 일반(평지) Foundation 위 머신을 직접 연결할 때, 높이차(평지 Foundation 상면 = 평면 + Thickness(45) + N×100 → 맨땅보다 항상 ≥45uu 위)만큼 경사 벨트가 Foundation 슬래브를 뚫고 올라가는(관통) 것을 금지. RampFoundation 낮은끝을 통해서만 연결하도록 강제.

- **경계쌍 게이트 추가** (`OJJ_Grid.cpp:399~` `OJJ_ValidateConveyorSlopePath` 혼합 raw↔Foundation 경로 STEP 루프): 경계쌍(`bCellIsFoundation` 전환)은 **① Foundation 셀이 `AOJJ_RampFoundation` + ② 경계 실제 ΔZ ≤ tol(1uu)** 일 때만 통과, 그 외 거부.
- **include 추가** (`OJJ_Grid.cpp:19`): `#include "OJJ_RampFoundation.h"` (Cast 대상 완전형).
- **검증 단일원 공유**: `OJJ_CollectConveyorReservedCells` → 호버 프리뷰(`OJJ_UpdateConveyorPathHoverPreview`)·배치(`OJJ_TryPlaceConveyor`)가 공유 → 호버 빨강 + 클릭 차단 자동.
- **이슈 #352 정정**: 제목/본문을 "Foundation 단차"에서 "컨베이어 관통 금지"로 수정(초기 오독 정리).

### 🟠 Major (Codex 발견 → 반영 완료)
- **램프 경계 클래스-only 허용의 관통 재발** (`OJJ_Grid.cpp:416` 경계쌍 판정)
  - 내용: 최초 구현은 경계 Foundation 셀이 램프이면 ΔZ 무관 통과시켰음. 램프 **높은끝/측면**으로 땅에서 진입하면 경계 ΔZ가 ~100uu라 경사 벨트가 슬래브를 다시 뚫음(`#261` 지면 클램프는 **낮은끝(r=0)만** 성립).
  - 영향: 가드 우회 → 관통 재발(Codex P2).
  - 제안: 클래스(Cast) + **경계 실제 ΔZ near-level(≤1uu)** 결합. → **반영 완료** (낮은끝만 ΔZ≈0이라 통과, 높은끝/측면은 거부).
