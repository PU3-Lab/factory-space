# 2026-06-20 코드 리뷰 03 — 채굴기 광맥인접 경사 배치 (1단계)

- **대상**: 채굴기(Miner)가 미선점 광맥에 인접하면 경사(Blocked) 셀에도 배치 허용. 경사 게이트만 면제, 나머지 게이트 유지.
- **리뷰 범위**: `OJJ_Grid.cpp` `CanPlaceMachine` 1곳 (+9줄)
- **리뷰 방식**: 다중 에이전트 정확성/스코프누수 검증
- **PIE**: 통과 (a)(b)(d) 핵심 — 광맥 옆 경사 배치 OK / 광맥 없는 경사 거부 / 점유·범위·Claim 작동
- **빌드**: 통과

## 변경 요약
`CanPlaceMachine` 루프 앞에서 `bMinerOreAdjacent = (MachineType=="MinerMachine") && CanPlaceAdditional(광맥 인접)` 선계산(게이트 순서 해결). 셀별 게이트 A에 `bSlopeExemptCell = bMinerOreAdjacent && IsCellBlocked(Cell)` 추가 → 경사(Blocked) 셀만 면제.

## 검증 (전부 PASS)
1. **경사만 면제**: `IsCellBlocked`=`UnbuildableCells`(경사 전용, Void/Water와 배타 — 베이크 커밋 단일 분류). Void(바닥없음)/Water는 면제 안 됨. ✅
2. **게이트 누수 없음**: 범위(`IsValidGridCell`)·점유(게이트 B `OccupiedCells`)·단일건설면(`OJJ_GetUniformSurfaceZ`, 루프 후)·`CanPlaceAdditional`(최종) 전부 그대로. `bSlopeExemptCell`은 게이트 A(IsCellConstructible)만 우회. ✅
3. **균일면 유지**: raw 경사 지형은 `OJJ_GetUniformSurfaceZ`가 최고 GroundZ로 통과(거부 안 함) → 면제가 실효. 혼합(Foundation+지형)만 거부(기존 정책). ✅
4. **FName 비교·조기 호출**: `GetMachineType()==TEXT("MinerMachine")` 기존 패턴(2758/4682) 동일. 조기 `CanPlaceAdditional`은 const·부작용 없음(`FindAdjacentUnclaimedOre` read-only). ✅
5. **다른 머신 무영향**: 문자열 정확 일치라 Conveyor/Warehouse/Pump/AirCompressor는 `bMinerOreAdjacent=false` → 경사 게이트 그대로. ✅

## 긍정적인 부분
- 광맥 인접 판정을 루프 앞으로 당겨 게이트 순서 문제를 정확히 해결.
- `IsCellBlocked`(경사 전용 set)로 면제 범위를 경사로 정밀 한정 — Void/Water/점유/범위 자동 보존.
- 채굴기 직접 체크로 다른 추출기(Pump/AirCompressor)까지 번지지 않게 한정.
- 경사 기울기(틸트)는 2단계로 분리 — 1단계는 "배치 가능 여부"만(디버깅 단순).
