# 2026-06-27 코드 리뷰 01 — TPS 빌드모드 ←/→ 카테고리 순환 + 슬롯1 자동선택

## 변경 요약

TPS 빌드모드(`EBuildViewMode::TPS`)에서 ←/→ 방향키로 설치 카테고리(기계/전력/건물)를 순환하고, 전환 시 새 카테고리의 슬롯1을 자동선택하는 기능.

- **대상 커밋:** `e6ffc4b` (기능) + 본 리뷰의 후속 수정
- **변경 파일 (C++ 4, 에셋 0):**
  - `Source/Wanted_Factory/Public/OJJ_Player.h` — 핸들러 3개 선언
  - `Source/Wanted_Factory/Private/OJJ_Player.cpp` — ←/→ `BindKey` + `CycleBuildCategory/Next/Prev` (TPS 가드 + 위젯 위임)
  - `Source/Wanted_Factory/UI/UI_BuildModeMain.h` — `CycleSubMode` 선언 + `bAutoSelectFirstSlotOnSwitch` 플래그
  - `Source/Wanted_Factory/UI/UI_BuildModeMain.cpp` — `CycleSubMode` 구현 + `OnHotbarOutFinished` 슬롯1 자동선택
- **설계 결정:** V진입은 `PlacementMode=None` 유지(`EnterBuildMode` 미변경) — 순환은 ←/→ 입력 시에만 발동. 입력은 레거시 `BindKey`(슬롯키 1~0과 동일 패턴) 사용 → IA/IMC 에셋 신설 0.
- **검증:** UE 5.7 풀 빌드 `Succeeded`. codex 교차검증(5개 항목) 수행.

## 이슈 목록

### 🟡 Minor — 슬롯1 자동선택 플래그 누수 (버튼 클릭 인터리브) — ✅ 수정 완료
- **위치:** `Source/Wanted_Factory/UI/UI_BuildModeMain.cpp:131-133` (카테고리 버튼 핸들러)
- **내용:** `CycleSubMode`가 `bAutoSelectFirstSlotOnSwitch=true`를 세운 뒤 `SwitchBuildSubMode`(out-애니 재생)를 호출하고, 플래그는 애니 완료 시점의 `OnHotbarOutFinished`에서 소비된다. 그런데 카테고리 버튼 핸들러(`OnMachineModeClicked` 등)는 플래그를 끄지 않고 `SwitchBuildSubMode`만 호출했다.
- **영향:** ←/→ 순환 애니 진행 중 사용자가 카테고리 버튼을 클릭하면, 직전 순환이 세운 플래그를 그 클릭의 `OnHotbarOutFinished`가 소비 → **버튼 클릭인데도 슬롯1이 자동선택**되어 "버튼 클릭은 자동선택 안 함"이라는 설계 의도를 위반. (순수 순환 경로는 항상 다른 카테고리라 early-return이 없어 누수 없음 — 인터리브 엣지에서만 발생.)
- **제안:** 3개 버튼 핸들러 진입부에서 `bAutoSelectFirstSlotOnSwitch = false;`로 명시 초기화.
- **조치:** 수정 적용 후 재빌드 `Succeeded`. 클릭이 항상 플래그를 끄므로 인터리브 시 클릭이 자동선택을 상속하지 않음.

## 우선순위 권고

1. **(완료)** 🟡 플래그 누수 수정 — 적용·빌드 검증됨.
2. **(선택, 후속)** ←/→ **연타 시 한 칸만 전진하는 한계**: `CycleSubMode`/`SwitchBuildSubMode`가 `CurrentSubMode`(애니 완료 전 미갱신)를 기준으로 다음 값을 계산하므로, out-애니 진행 중 빠른 연타는 같은 목적지로 덮어써져 한 칸만 이동할 수 있다. 기능상 치명적이지 않아 MVP 범위에서 보류 가능. 개선하려면 `PendingSubMode` 기준 계산 또는 애니 진행 중 입력 무시 가드 도입.

## 긍정적인 부분

- 기존 `ExecuteHotbarSlot`(위젯 위임) 패턴을 그대로 재사용해 일관성 높음. 위젯 참조·null 가드·로그 형식이 선례와 동일.
- 레거시 `BindKey` 선택으로 IA/IMC 에셋 신설·BP 할당 없이 C++만으로 완결 — 머지 충돌·에디터 의존 최소화.
- `EnterBuildMode`의 None-start 설계를 건드리지 않아 V진입 동작 회귀 없음.
- 슬롯1 자동선택 타이밍을 `OnHotbarOutFinished`(CurrentSubMode flip 직후)로 정확히 배치 — 순서 버그 회피.
- 플래그 게이트로 순환 경로와 버튼 클릭 경로를 분리해 기존 UX 보존(누수 수정 후 완전 분리).
