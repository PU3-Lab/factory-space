## 변경 요약
평지 Foundation(Deck 슬래브 + 4모서리 TrussTower 다리) 개편에 이어 **램프**를 동일 Deck 미감으로 통일.

1. **램프 Deck 틸트** (`AOJJ_RampFoundation::UpdateSlabVisual` 재작성)
   - 기존: 베이스 Deck(SlabMesh)를 숨기고 절차생성 WedgeMesh로 경사면 렌더.
   - 변경: Deck를 빗변길이 `Hyp=√(L²+Rise²)`로 스케일 + `pitch=atan2(Rise,L)` 틸트해 보이는 경사면으로 사용. 상면중심 `P=(0,0,Thickness)` 피벗 회전 후 `+Rise/2` 보정 → 상면이 저끝 `Z=액터Z+Thickness` → 고끝 `+Rise` (쐐기 빗변과 동일 평면).
   - Deck 회전엔 **pitch만** — 액터가 `yaw=90×step` 부여(`OJJ_BuildController.cpp:1385`)하므로 이중 yaw 금지.
   - WedgeMesh는 `SetVisibility(false)`로 시각만 끄고 **convex 충돌 유지**(보행 전담).
2. **램프 다리 미적용** (`UpdateLegVisual` virtual화 + 램프 override)
   - 베이스 `AOJJ_Foundation::UpdateLegVisual`을 `virtual`로 전환, 램프는 override해 베이스 4모서리 로직 미호출·`LegISM->ClearInstances()`만. 평지는 무영향.
3. **부수효과 해소**: 쐐기가 Deck 머티리얼을 복사(`OJJ_BuildWedgeVisual` 내)해 색이 바뀌던 이슈 → 쐐기 미렌더로 자동 해소(Deck 자기 머티리얼).
4. **빗변 갭(결정 B)**: PIE에서 갭이 안 보여 **연장 미처리(연장 포기)** — 코드 변경 없음.

## 이슈 목록

### 🟡 Minor — wedge 미생성 폴백이 `Rise<1` 전용임을 명시 안 함
- **위치**: `OJJ_RampFoundation.cpp:527` 부근 (`SetCollisionEnabled(bWedgeBuilt ? NoCollision : QueryOnly)`)
- **내용**: `!bWedgeBuilt` 분기가 의도(평지 브리지 `Rise<1`)뿐 아니라 **경사 램프에서 wedge 생성이 예기치 않게 실패한 경우**까지 Deck QueryOnly 충돌로 흡수한다.
- **영향**: 경사 램프 wedge 실패 시 과거 wedge/계단 충돌 거동이 보존되지 않고 박막 Deck 충돌로 대체됨(여전히 보행은 가능하나 무음으로 회귀 경로가 열림).
- **제안**: 폴백을 `Rise<1`로 한정하거나, 경사 `!bWedgeBuilt`에 경고 로그/assert를 추가해 예기치 않은 실패를 가시화.

### ⚪ Nit — 은퇴한 `StepMeshISM` 데드 코드
- **위치**: `OJJ_RampFoundation.cpp:515` 부근 (`StepMeshISM->ClearInstances()`만 남음)
- **내용**: 계단 박스 폴백 은퇴 후 `StepMeshISM`은 정리 호출만 남아 사실상 데드 런타임 비주얼/충돌 코드. (직렬화/에디터 잔여 정리 목적이면 의도적.)
- **영향**: 기능 영향 없음. 컴포넌트/프로퍼티/생성자 셋업이 잔존.
- **제안**: 하위호환 불필요 시 별도 클린업 패스에서 컴포넌트 제거. 유지면 무방.
