# 2026-06-20 코드 리뷰 04 — 채굴기 경사 틸트 배치 (2단계)

- **대상**: 채굴기(Miner)를 경사면 기울기에 맞게 틸트 배치. 1단계(광맥인접 경사배치 #310) 후속.
- **리뷰 범위**: `OJJ_Grid.h`/`OJJ_Grid.cpp`(신규 3함수), `OJJ_BuildController.cpp`(배치 트랜스폼 적용)
- **리뷰 방식**: 다중 에이전트 + PIE 실측 교차검증
- **PIE**: 통과 (a)~(g) — 경사 틸트 / 평지 무틸트 / 모서리 묻힘·뜸 없음(c) / yaw+틸트 합성(d) / 다른 머신 회귀 0(e) / 세이브·로드 유지(f) / 1단계 무회귀(g)
- **빌드**: 통과

## 변경 요약
- `OJJ_ComputeFootprintTerrainPlane`(private): 풋프린트 4코너 하향 라인트레이스(BakeBuildableCells 동일 채널·머신/자원/Foundation 무시)로 지형 법선 + 중심 Z 산출. void 코너면 false(틸트 미적용).
- `OJJ_GetMachineTiltRotation`: 채굴기 & raw 경사 & 평지아님일 때만 `FindBetweenNormals(Up, Normal)` 틸트, 그 외 ZeroRotator.
- `OJJ_GetMachinePlacementTransform`: 틸트0이면 기존(FlatLoc+yaw) 그대로, 채굴기-경사면 메시 바닥-중심을 지형평면 중심에 안착 + 회전 `Tilt*Yaw`.
- `OJJ_BuildController.cpp`: yaw-only `SetActorRotation` → `OJJ_GetMachinePlacementTransform` 결과를 `SetActorLocationAndRotation`(scale 불변).

## 검증 (전부 PASS)
1. **회귀 격리**: `Tilt.IsNearlyZero()`(비채굴기/평지/Foundation/평지법선) → `FTransform(Yaw, FlatLoc, Scale)` = 기존 TryPlaceMachine 위치(FlatLoc)+yaw와 동일. `SetActorLocationAndRotation`은 scale 미변경. → 다른 머신·평지 채굴기 무회귀(PIE e). ✅
2. **법선/gradient 부호**: `Normal=(-dZdX,-dZdY,1)` → 메시가 슬로프와 같은 방향 틸트(PIE a/d 시각 확인, 반전 없음). ✅
3. **회전 합성**: `Tilt*Yaw`(yaw 먼저→틸트), `FindBetweenNormals`는 yaw 성분 없는 최소회전. PIE d 통과. ✅
4. **Z 안착**: `ActorZ = CenterZ − Full.Rotate(BottomCenterLocal).Z` → 바닥-중심을 지형평면 중심에 안착, 바닥면∥지형면이라 전체 안착. PIE c(묻힘/뜸 없음) 통과. ✅
5. **이중 트레이스**: transform이 tilt rotation + plane을 각각 트레이스하나 동일 프레임 정적 지형이라 결정적·일치. 비용 무시(배치 1회 8트레이스). ✅
6. **빌드**: include(FQuat/FBox/TActorIterator/AConveyor/AResourceBase/AOJJ_Foundation 기존 bake 공유)·접근지정자(private 헬퍼 삽입 후 public 복원)·미사용 변수 오류 없음. ✅
7. **세이브/로드**: full Transform 저장·복원(FactorySaveSubsystem) → 틸트 자동 보존(PIE f). ✅

## 이슈 (Blocker 0 · Major 0 · Minor 0 · Nit 1)

### ⚪ Nit — 피벗 의존(메시)
- 결합 Z안착이 메시 AABB 바닥-중심 기준이라, SM_Miner 피벗이 중심·바닥에서 크게 벗어나면 틸트 시 XY 소량 쏠림 가능. PIE 관찰 결과 문제 없어 메시 미변경(.uasset 없음). 추후 어긋남 보이면 JJ가 피벗 조정(협의됨).

## 우선순위 권고
- **승인(APPROVE)**. 외과적, 회귀 0 격리(IsNearlyZero), 코너 트레이스 정확 법선 + 결합 transform 모서리 안착. PIE 전 항목·빌드 통과.

## 긍정적인 부분
- 위치+회전을 한 함수에서 일관 산출 → "위치 후 별도 회전" 결합 문제 해소.
- 틸트0 조기반환으로 비채굴기/평지 경로를 기존과 **비트 동일**하게 보존(회귀 0).
- 코너 실측 트레이스로 quant(셀최고점) 방향 손실 없이 정확한 슬로프 법선.
- 세이브/로드는 기존 Transform 직렬화로 무비용 자동 보존.
