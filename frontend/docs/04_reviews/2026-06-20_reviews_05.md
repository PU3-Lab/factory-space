# 2026-06-20 코드 리뷰 05 — 일반 바닥 직배치를 Foundation-전용 제한 (직배치 1단계)

- **대상**: 일반 바닥(raw 지형) 직접 설치를 `CanPlaceOnRawGround()` 머신(채굴기)만 허용, 나머지 AMachineBase는 Foundation 위에만.
- **리뷰 범위**: `MachineBase.h`(virtual 추가), `MinerMachine.h`(override), `OJJ_Grid.cpp`(`CanPlaceMachine` 게이트)
- **리뷰 방식**: 다중 에이전트 + 직접 검증 + PIE
- **PIE**: 통과 (a)~(g) — raw 거부 / Foundation 허용 / Miner raw·경사 유지 / 별도액터 무관 / Pump water 유지 / 맵 로드 무삭제
- **빌드**: 통과

## 변경 요약
- `MachineBase::CanPlaceOnRawGround()` 기본 false(Foundation 위만). Miner override true.
- `CanPlaceMachine`: 셀이 `IsCellBuildable && !IsCellOnFoundation`(raw 지상)인데 `!bWaterCellOk && !CanPlaceOnRawGround()`면 거부. 게이트 A 직후, 점유(B) 앞.

## 검증 (전부 PASS)
1. **override 범위**: grep 확인 — Miner만 true. Warehouse/Smelter/Grinder/Synthesizer/Molding/LiquidTank/PowerPlant 등 전부 default false → Foundation 위만. ✅
2. **Pump/water 직교**: water 셀은 `IsCellBuildable`=false(WaterCells 제외) → `bRawGroundCell`=false. + `bWaterCellOk`로 skip. Pump water 통과, Pump raw 지상 거부. ✅
3. **Foundation**: `IsCellOnFoundation` true → `bRawGroundCell`=false → 전 머신 통과(무회귀). ✅
4. **Miner 경사(1단계)**: Blocked 셀 `IsCellBuildable`=false → 새 게이트 무관, 게이트 A의 `bSlopeExemptCell`가 처리. Miner 경사 배치 유지. ✅
5. **별도 액터**: Foundation/Ramp(`CanPlaceFoundation`)·Conveyor/Pipe(자체 경로)는 `CanPlaceMachine` 비경유 → 무영향(raw 그대로). ✅
6. **CDO-safe**: override는 상수 반환(인스턴스 상태 미사용) — 호버 CDO 판정 안전. ✅
7. **세이브**: 맵에 규칙 위반 배치 없음(JJ 확인) → 폴백 불필요, FactorySaveSubsystem 미변경. 레벨 사전배치는 occupancy-only 경로로 게이트 우회(안전). ✅

## 이슈 (Blocker 0 · Major 0 · Minor 0 · Nit 1)

### ⚪ Nit (전방 주의) — 추출 머신 AirCompressor
- AirCompressor는 Miner와 동일 패턴(`CanPlaceAdditional`→`FindAdjacentGas`, 인접 가스 자원 필요)이나 `CanPlaceOnRawGround` override 없음 → default false(Foundation 위만).
- **현재 영향 0**: AirCompressor는 빌드모드 배치 경로(BuildController/PlacementMode/핫바)에 미연결 → 게이트가 실무에 작동 안 함.
- **조치**: 향후 AirCompressor(또는 다른 추출/수원 머신)를 빌드모드에 연결할 때, 자원 옆 raw 배치가 필요하면 `CanPlaceOnRawGround() override return true` 추가(Miner와 동일). 이번 비차단.
