## 변경 요약

파이프 시각 라이저가 높은 셀(솔리드 데크) **중심**에 수직으로 떨어져 데크 슬래브를 관통하던 것을, **솔리드 셀(IsCellOnFoundation ∧ 비오버패스)일 때 라이저를 셀 엣지 밖**(셀중심 + 이웃방향 `HalfCell + OJJ_PipeEdgeDropMargin`)으로 이동(ㄴ자). 진입(지면→Foundation)·이탈(Foundation→지면) 대칭 처리. 오버패스 다리(공중)는 플래그 false라 기존 셀중심 ㄷ자 유지(#257 회귀 방지). 마진은 파이프 반지름 몸체가 모서리 스치는 것까지 막는 여유.

- **plumbing**: 그리드가 `IsCellOnFoundation(cell) && !bBridge[i]`로 플래그 산출 → `OJJ_SetPathCellEdgeRisers`(길이검증) → Pipe가 `IsValidIndex` 가드로 읽음. `SetPath`서 stale 리셋.
- 충돌 = `SegmentInstances`(시각 = 충돌) → 노드 이동이 시각+충돌 동시 교정.

## 검증 (리뷰어 6개 포커스 — 전부 PASS)

1. **플래그 plumbing**: 호출 순서 SetPath(리셋) → SetPathCellEdgeRisers(검증) → SetPathCellLocalZs(RebuildVisuals). 인덱스 정합(둘 다 post-dedup `GetPathCells` 기준). ✅
2. **라이저 수식**: 파이프 4-연결이라 `StepToPrev/Next`가 단위 축 벡터 → `EdgeOffset=HalfCell+margin`이 엣지 라인+마진에 정확 안착(대각 오버슈트 없음). 진입/이탈 양쪽 올바른 방향. ✅
3. **오버패스 무변경**: `!bBridge[i]`로 다리 셀 flag=false → else 분기 byte-identical. **#257/F4-3 회귀 없음**. ✅
4. **데크 상면 불변**: 파이프 노드 XY/Z만 변경, Foundation SurfaceZ(ActorZ+Thickness) 무관 → 머신/사다리/등반 무영향. ✅
5. **충돌**: SegmentInstances가 시각+충돌 겸용 → 동시 교정, stale 경로 없음. ✅
6. **엣지케이스**: 재경로 stale 리셋 / 길이불일치 all-false 폴백 / 단일셀 가드 / 단일 Foundation 셀(진입+이탈 동시) 클린 시퀀스 / zero-length 스킵. ✅

## 이슈 목록 (Blocker 0 · Major 0 · Minor 3 · Nit 2) — 전부 비차단

### 🟡 Minor — `OJJ_PipeEdgeDropMargin` ClampMin=0이 안전최소 주석과 모순 (후속)
- **위치**: `Pipe.h:80`(ClampMin "0.0") / `Pipe.cpp:294`
- **내용**: margin=0이면 `EdgeOffset=HalfCell`라 라이저 중심이 데크 엣지 라인에 딱 붙어 파이프 반지름(30) 몸체가 모서리 반쯤 겹침 — 마진이 막으려던 그 스침 재발. 주석은 안전최소를 `≈PipeRadius+α`로 명시하나 clamp는 그 아래도 허용.
- **영향**: 기능 결함 아님(기본 40 안전). 디자이너 footgun.
- **제안(후속)**: ClampMin을 반지름 유도 하한으로 올리거나, 사용처에서 `FMath::Max(margin, PipeRadius)`로 바닥 처리.

### 🟡 Minor — margin이 PipeRadius를 추종 안 함 (후속)
- **위치**: `Pipe.h:80` 기본 40("반경 30 + 10")
- **내용**: 기본 마진이 PipeRadius 손튜닝값. PipeRadius 편집 시 마진 미추종 → 스침 재발 가능.
- **제안(후속)**: 사용처서 `FMath::Max(OJJ_PipeEdgeDropMargin, PipeRadius + Slack)` 유도, 또는 "PipeRadius 변경 시 마진 재튜닝" 주석.

### 🟡 Minor — `OnConstruction` 경로가 stale `PathCellEdgeRiser`로 렌더 가능(일시·무해)
- **내용**: 에디터에서 OnConstruction이 다음 SetPath 전 rebuild 시 옛 플래그 사용 가능. `IsValidIndex` 가드로 최악도 옛 셀중심 라이저 → 일시 에디터 코스메틱, 런타임 결함 아님. 조치 불필요.

### ⚪ Nit — 엣지 오프셋 계산 중복(Pipe.cpp:302-303, 319-320) / ⚪ Nit — `Nodes.Reserve(NumCells+4)` 과소예약(엣지셀당 +2). 둘 다 무해.

## 긍정적인 부분

- 길이검증 세터 + IsValidIndex 리더 + 재경로 리셋 = all-false 폴백으로 **오버패스 기존 동작 증명적 보존**. 옵션 채널 추가의 모범.
- 오버패스 제외(`&& !bBridge[i]`)를 단일 진실원에 두고 기존 bridge 배열 재사용 — 표면적 최소, 제외 셀 byte-identical.
- SegmentInstances 시각+충돌 겸용 재사용 → 시각/충돌 divergence 원천 차단.
- "파이프 메시 Z를 충돌 질의에 쓰지 말 것" 등 기하 의도 한글 주석 충실.
