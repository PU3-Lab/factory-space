# 2026-06-21 리뷰 01 — Foundation 고스트 프리뷰 (일반 Nanite + 램프 신설) + 배치 셀 그리드 데크 리프트

## 변경 요약

빌드모드 Foundation 미리보기/오버레이 표시 3건 수정. 호버 타일 "부분부분" 버그는 별도 보류(미접촉).

- **1. 배치 셀 그리드 타일 데크 위 리프트** (`OJJ_Grid.cpp` `OJJ_GetCellVisualBaseZInternal`): Foundation 분기가 `SurfaceZ`(데크 윗면)만 반환해 타일이 +3uu만 떠 z-fighting(각도 따라 깜빡임). 지형/물 셀과 동일하게 `+ VisualZLift` 적용해 데크 위로 충분히 띄움(비대칭 해소).
- **2. 일반 Foundation 고스트(Nanite)** (`OJJ_Grid.cpp` `OJJ_ShowGhostForFoundation`): `SetForceDisableNanite(true)` 추가. Nanite 메시는 `SetOverlayMaterial`(고스트 틴트 패스)을 안 그려(UE5.7+Substrate) Deck Nanite 메시의 고스트만 안 보였음. 머신/사다리 고스트와 동일 패턴.
- **3. 램프 Foundation 고스트 신설** (`OJJ_Grid.cpp`/`.h`/`OJJ_BuildController.cpp`): `OJJ_ShowGhostForRamp` 추가. `RampFoundation::UpdateSlabVisual`의 틸트 산식(빗변 스케일 + 상면중심 피벗 pitch θ) 재현 + 액터 yaw 합성. 램프 분기 `OJJ_HideGhost` → `OJJ_ShowGhostForRamp`로 교체.

## 이슈 목록

### 🟡 Minor
- **램프 고스트 one-side-ground 프리뷰 Z 불일치** (`OJJ_Grid.cpp` `OJJ_ShowGhostForRamp` SnapLift)
  - 내용: CDO의 가상 `OJJ_ComputeSnapLift` 호출 시 placed 상태(`bPlacedOneSideGroundRamp`/`PlacedRiseSteps`)가 기본값이라, one-side-ground 하강 자동 램프에서 높은끝 스냅 미반영 → 낮은끝 지형 폴백.
  - 영향: **프리뷰 전용** — 해당 램프 타입에서 고스트 Z가 실제 배치와 미세 차이. **배치는 Fit으로 정상(무영향), mutation 없음.** 일반 램프 PIE 정상.
  - 제안: Fit의 one-side-ground 데이터를 `OJJ_ShowGhostForRamp`에 넘겨 명시 계산. → **후속 이슈 #322, 코드 KNOWN-LIMIT 주석.**

### ⚪ Nit
- **`const AOJJ_Foundation*` 가능** (`OJJ_ShowGhostForRamp` 파라미터) — 포인터 변형 없음. 평판 고스트와 시그니처 일관 위해 현행 유지.
- **`RampGhostReason` 미사용** (`OJJ_BuildController.cpp` 램프 분기) — `CanPlaceFoundation` out 파라미터 충족용. 평판 분기와 동일 패턴이라 허용.
