## 변경 요약

파이프가 셀별 raw 지형 Z(`OJJ_GetPipeCellSurfaceZ`)를 그대로 추종해 미세 굴곡마다 잔 꺾임이 생기던 것을, **"구간 최고점 수평 plateau + 단차 임계서만 꺾음"**으로 단순화.

- `OJJ_FlattenLiftToPlateaus`(익명 ns): forced breakpoint(끝점/XY 코너/오버패스 다리)는 raw 고정, 그 사이 셀을 vertical span(최고−최저) ≤ `OJJ_PipeLiftStepTolZ`인 연속 run으로 묶어 각 run을 **최고 lift로 수평**(낮은 셀은 떠 있음 — 압송이라 OK). span 초과 시 run을 끊어 단차로 꺾음.
- span 기준이라 band 양자화의 경계 flicker 없음, float ≤ tol로 유계. `Pipe.cpp:365`가 동일높이 연속 노드에 조인트를 안 박아 run 내부 잔 꺾임 소멸.
- 장부 `CellZs`(레이어/오버패스 판정)는 raw 유지 — 시각 lift만 평탄화.
- 튜너블 `OJJ_PipeLiftStepTolZ`(기본 100uu, EditAnywhere, 0=비활성=raw 추종).

## 검증(리뷰어 4개 포커스 — 전부 통과)

1. **run-partition/flatten 로직·인덱스 안전**: two-pointer 스윕, `i` 단조 증가, `[RunStart, j)` half-open 검증 인덱스, span 테스트가 초과 셀 커밋 *전* break → off-by-one/OOB 없음. ✅
2. **엣지케이스**: 빈 경로(`N==0`)/단일 셀/all-fixed/연속 코너/다리 경계/`TolZ==0`(비활성)/`bFixed.Num()!=N` 모두 가드. ✅
3. **시각/장부 desync 무해**: 평탄화는 `BaseLift→CellLifts→PathCellZs`(시각 메시 Z)만 변경. 충돌/오버패스(`ElevatedFlags`)/흐름(`OccupiedGridCells`/`LiquidSlots`)은 전부 그리드 셀·장부 기반이라 무관. ✅
4. **끝점/다리 보존**: 끝점 `bFixed[0/ N-1]` raw → 펌프/탱크 포트 안 뜸/안 박힘. 다리 셀 fixed raw + 클리어런스 재합성 → ㄷ자 비트-동일 보존. ✅
