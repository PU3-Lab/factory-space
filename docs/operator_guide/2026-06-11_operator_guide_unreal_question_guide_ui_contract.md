# operator_guide 질문 가이드 Unreal UI 문서

## 목적

operator_guide NPC 대화 UI에서 플레이어가 어떤 질문을 할 수 있는지 자연스럽게 안내한다.

질문 가이드는 모든 답변 앞에 자동으로 붙는 안내문이 아니다. Unreal NPC 대화 UI 안의 별도 탭으로 제공하고, 플레이어가 필요할 때 직접 확인하는 도움말 패널로 사용한다.

단, 질문 가이드 탭이 숨겨진 기능처럼 느껴지지 않도록 `질문하기` 탭 안에도 작은 진입점인 "질문 예시 보기" 버튼 또는 링크를 둔다.

UI 톤은 **튜토리얼 퀘스트 안내판 70% + NPC 수첩 30%**로 잡는다. FAQ처럼 딱딱한 문서가 아니라, 게임 안에서 플레이어가 다음 질문을 고르기 쉽게 도와주는 안내판에 가깝다.

## 추천 UI 구조

```text
NPC 대화 UI

[질문하기] [질문 가이드]

질문하기 탭
- 플레이어 자유 질문 입력
- NPC 답변 표시
- sources / confidence / recommended_actions 표시
- 작은 진입점: "질문 예시 보기"

질문 가이드 탭
- 질문 가능 범위 안내
- 질문 카테고리
- 예시 질문 버튼
- 더 정확히 질문하는 팁
```

## UI 톤 결정

```text
선택 방향:
튜토리얼 퀘스트 안내판 70% + NPC 수첩 30%

의도:
- 플레이어가 게임 안에서 자연스럽게 도움을 받는 느낌
- 너무 딱딱한 FAQ/매뉴얼처럼 보이지 않게 하기
- NPC가 "이런 식으로 물어보면 내가 도와줄 수 있어"라고 알려주는 톤
- 포트폴리오 설명 시 플레이어 온보딩까지 고려한 UI로 설명 가능
```

문구 톤 예시:

```text
공장 운영이 막혔다면 이렇게 물어봐요.
장비, 자원, 제작법, 전력, 물류, 고장 원인을 중심으로 물어보면
공장 매뉴얼을 찾아서 도와드릴게요.
```

## 최종 UX 방향

```text
기본 구조:
[질문하기] [질문 가이드] 탭을 나눈다.

보완:
질문하기 탭 안에도 작은 "질문 예시 보기" 버튼/링크를 둔다.

이유:
- 답변 흐름과 도움말을 분리할 수 있다.
- 처음 보는 플레이어가 질문 가이드를 발견하기 쉽다.
- 질문하다 막힌 플레이어가 바로 예시를 확인할 수 있다.
- 구현 난이도는 낮고 UX 효과는 크다.
```

추천 흐름:

```text
NPC에게 상호작용
-> 기본은 [질문하기] 탭
-> 입력창 근처에 "질문 예시 보기" 표시
-> 플레이어가 클릭하면 [질문 가이드] 탭으로 이동
-> 예시 질문 버튼을 누르면 [질문하기] 탭으로 돌아오고 입력창에 질문 자동 입력
-> 플레이어가 필요하면 수정 후 전송
```

## 질문 가이드 탭 화면

질문 가이드 탭을 누르면 NPC가 새로 말하는 것이 아니라, 아래처럼 도움말 패널이 열린다.

```text
┌────────────────────────────────────────┐
│ NPC 도움말                              │
│ [질문하기] [질문 가이드]                 │
├────────────────────────────────────────┤
│ 이렇게 물어볼 수 있어요                  │
│                                        │
│ 장비, 자원, 제작법, 전력, 물류,          │
│ 고장 원인을 중심으로 물어보면             │
│ 공장 매뉴얼을 찾아서 도와드릴게요.        │
│                                        │
│ 장비                                    │
│ [제련기는 뭐야?]                         │
│ [컨베이어는 어디에 써?]                   │
│                                        │
│ 제작법                                  │
│ [기어는 어떻게 만들어?]                   │
│ [철괴를 만들려면 어떤 장비가 필요해?]      │
│                                        │
│ 문제 해결                               │
│ [컨베이어가 멈췄는데 뭘 확인해야 해?]     │
│ [철괴가 안 만들어져. 왜 그래?]            │
│                                        │
│ 더 정확히 물어보는 팁                    │
│ - 장비 이름을 같이 말하면 더 정확해요.    │
│ - "안 돼"보다 상황을 구체적으로 말해줘요. │
│ - 선택한 장비가 있으면 상태도 볼 수 있어요.│
└────────────────────────────────────────┘
```

## 표시 원칙

```text
- 질문 가이드 탭은 플레이어가 직접 눌렀을 때만 열린다.
- 관련 질문에 대한 답변 앞에 자동으로 붙지 않는다.
- 범위 밖 질문이나 애매한 질문에서는 "질문 가이드 탭을 확인해 주세요" 정도로만 안내한다.
- 예시 질문은 텍스트보다 버튼 형태를 우선 추천한다.
```

## 예시 질문 버튼 동작

기본 동작은 "바로 전송"이 아니라 "입력창에 채우기"다.

```text
1. 플레이어가 [기어는 어떻게 만들어?] 버튼 클릭
2. UI가 [질문하기] 탭으로 이동
3. 질문 입력창에 "기어는 어떻게 만들어?" 자동 입력
4. 플레이어가 필요하면 문장을 수정
5. 플레이어가 전송 버튼을 눌러 질문
```

이 방식은 플레이어가 예시 질문을 자기 상황에 맞게 수정할 수 있고, 실수로 버튼을 눌렀을 때 바로 질문이 전송되는 문제를 줄인다.

## 역할 분리

```text
Unreal / Front
- NPC 대화 UI 구현
- [질문하기] / [질문 가이드] 탭 전환 구현
- 질문 입력창 구현
- 질문하기 탭 안의 "질문 예시 보기" 버튼/링크 구현
- 질문 가이드 목록/버튼 표시
- 예시 질문 버튼 클릭 시 질문 입력창 채우기
- recommended_actions에 따라 "질문 가이드 보기" 버튼 표시

Backend / operator_guide
- 질문 답변 생성
- RAG 검색
- 현재 게임 상태 필요 여부 판단
- 범위 밖 질문 처리
- 질문 가이드에 표시할 카테고리/예시 데이터 제공
- 최종 응답 JSON에 sources, confidence, metadata 포함
```

## 질문 가이드 데이터 예시

Backend가 아래 형태의 데이터를 제공하면 Unreal은 카테고리, 예시 질문 버튼, 팁으로 렌더링한다.

```json
{
  "guide_title": "이렇게 물어볼 수 있어요",
  "tone": "tutorial_quest_board_with_npc_notebook",
  "tone_ratio": {
    "tutorial_quest_board": 0.7,
    "npc_notebook": 0.3
  },
  "description": "장비, 자원, 제작법, 전력, 물류, 고장 원인을 중심으로 물어보면 더 정확히 도와줄 수 있어요.",
  "categories": [
    {
      "name": "장비",
      "examples": ["제련기는 뭐야?", "컨베이어는 어디에 써?"]
    },
    {
      "name": "자원",
      "examples": ["철광석은 어디에 써?", "구리괴는 어떤 제작에 필요해?"]
    },
    {
      "name": "제작법",
      "examples": ["기어는 어떻게 만들어?", "철괴를 만들려면 어떤 장비가 필요해?"]
    },
    {
      "name": "문제 해결",
      "examples": ["컨베이어가 멈췄는데 뭘 확인해야 해?", "철괴가 안 만들어져. 왜 그래?"]
    },
    {
      "name": "진행 방향",
      "examples": ["다음엔 뭘 만들어야 해?", "지금 단계에서 어떤 장비를 먼저 설치해야 해?"]
    }
  ],
  "tips": [
    "장비 이름을 같이 말하면 더 정확해요.",

```

## 범위 밖 질문 처리

범위 밖 질문은 길게 설명하지 않고, 짧게 범위를 안내한 뒤 질문 가이드 탭으로 유도한다.

```text
플레이어:
오늘 날씨 어때?

NPC:
그 질문은 내 공장 매뉴얼 범위 밖이에요.
나는 장비, 자원, 제작법, 전력, 물류, 고장 원인에 대해 도와줄 수 있어요.
예시는 질문 가이드 탭에서 확인해 주세요.
```

응답 JSON 예시:

```json
{
  "final_answer": "그 질문은 내 공장 매뉴얼 범위 밖이에요. 장비, 자원, 제작법, 전력, 물류, 고장 원인에 대해 도와줄 수 있어요. 예시는 질문 가이드 탭에서 확인해 주세요.",
  "question_type": "out_of_scope",
  "sources": [],
  "confidence": "low",
  "recommended_actions": [
    {
      "type": "open_question_guide_tab",
      "label": "질문 가이드 보기"
    }
  ],
  "metadata": {
    "selectedAgent": "operator_guide",
    "selectedLeafAgent": "unknown_question",
    "guideSuggested": true
  }
}
```

## 애매한 질문 처리

질문이 너무 짧거나 애매하면 바로 가이드 전체를 출력하지 않고, 짧은 재질문과 예시를 준다.

```text
플레이어:
안 돼.

NPC:
어떤 장비나 제작이 안 되는지 알려주면 더 정확히 확인할 수 있어요.
예를 들면 "철괴가 안 만들어져" 또는 "컨베이어가 멈췄어"처럼 물어봐 주세요.
```

## Unreal 액션 타입

```text
open_question_guide_tab
- 질문 가이드 탭을 연다.
- 질문하기 탭의 "질문 예시 보기" 버튼도 이 액션과 동일하게 동작한다.

use_example_question
- 예시 질문을 질문 입력창에 채운다.
- payload 예시: `{ "question": "기어는 어떻게 만들어?" }`

show_source_detail
- 답변 근거 문서를 펼쳐 보여준다.
```

## 협의 포인트

- 질문 가이드는 자동 출력이 아니라 별도 탭으로 둔다.
- UI 톤은 튜토리얼 퀘스트 안내판 70% + NPC 수첩 30%로 잡는다.
- 질문하기 탭에는 작은 "질문 예시 보기" 진입점을 둔다.
- 관련 질문은 바로 답변한다.
- 범위 밖 질문은 짧게 안내하고 `open_question_guide_tab` 액션을 내려준다.
- 예시 질문은 버튼으로 제공하고, 기본 동작은 질문 입력창에 채우기로 한다.
- Backend는 질문 가이드 데이터를 JSON으로 제공하고, Unreal은 이를 UI로 렌더링한다.
