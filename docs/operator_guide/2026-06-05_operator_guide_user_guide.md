# Manual Q&A Agent 사용자용 설명

## 한 줄 설명

Manual Q&A Agent는 플레이어가 장비, 자원, 레시피, 문제 해결에 대해 질문하면 게임 매뉴얼 데이터를 보고 이해하기 쉬운 답변을 돌려주는 안내 에이전트입니다.

## 무엇을 물어볼 수 있나요?

현재 프로토에서는 5개 CSV에 들어 있는 정보만 답할 수 있습니다.

```text
장비
- 제련기는 뭐야?
- 채굴기는 뭐야?
- 컨베이어는 뭐야?

자원
- 철괴는 어떻게 만들어?
- 구리괴는 어떻게 만들어?
- 전력은 어떻게 만들어?

레시피
- 기어 만들려면 뭐가 필요해?
- 기본 모터 만들려면 뭐가 필요해?

문제 해결
- 제련기가 왜 안 돌아가?
- 컨베이어가 막혔을 때 뭘 확인해?
- 전력이 부족하면 어떻게 해야 해?
```

## 플레이어 화면에는 무엇이 보이나요?

Unreal UI는 응답 JSON에서 `payload.final_answer`만 화면에 표시하면 됩니다.

예시 질문:

```text
기어 만들려면 뭐가 필요해?
```

화면에 표시될 답변:

```text
좋아요. 기어를 만들려면 철괴 2개가 필요합니다. 조립기에서 제작하고, 흐름은 철광석 채굴 > 철괴 제련 > 조립기에서 기어 제작 순서로 보면 됩니다. 먼저 필요한 재료가 장비까지 들어오는지 확인해볼까요?
```

## 답변과 추천 행동은 다릅니다

플레이어가 보는 답변은 `final_answer`입니다.

추천 행동은 `metadata.recommended_actions`에 들어갑니다. 이것은 Unreal이 즉시 실행하는 명령이 아니라, 나중에 UI 버튼이나 안내 카드로 보여줄 수 있는 정보입니다.

```text
final_answer
-> 플레이어에게 보여주는 말

metadata.recommended_actions
-> 개발자와 UI가 참고할 수 있는 추천 확인 행동

payload.actions
-> 실제 Unreal 실행 action
-> 프로토에서는 항상 빈 배열
```

## 모르는 질문은 어떻게 답하나요?

CSV에 없는 질문은 지어내지 않습니다.

예시:

```text
우주 엘리베이터는 어떻게 업그레이드해?
```

답변 방향:

```text
그 질문은 현재 매뉴얼 데이터에서 확인할 수 없습니다.
저는 장비, 자원, 레시피, 생산 문제 해결을 도와드릴 수 있어요.
```

## 현재 프로토의 한계

현재 프로토는 실제 게임 상태를 읽지 않습니다.

예를 들어 플레이어가 `제련기가 왜 안 돌아가?`라고 물어도, 지금 당장 제련기에 철광석이 있는지, 전력이 부족한지 직접 확인하지는 않습니다.

프로토 답변은 CSV 매뉴얼에 기반한 일반 안내입니다.

최종 단계에서는 player_state, PostgreSQL, pgvector, LLM을 붙여서 실제 상황에 맞는 답변으로 고도화합니다.
