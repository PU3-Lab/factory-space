# 코드 리뷰 — 로봇 포트레이트 자동 스폰(WorldSubsystem)

- **날짜**: 2026-06-28
- **리뷰 번호**: 04
- **대상**: `UOJJ_PortraitCaptureSubsystem`, `UOJJ_PortraitSettings`, `OJJ_PortraitCapture` 생성자 RT 로드
- **리뷰 방식**: Codex(codex:rescue) 교차 리뷰
- **담당**: OJJ (오재준)

## 변경 요약

파이썬 수동 스폰을 대체하는 자동 스폰 도입.

- `UOJJ_PortraitCaptureSubsystem` (UWorldSubsystem): `OnWorldBeginPlay`에서 IsGameWorld 가드 → 데디 서버 제외 → `AutoSpawnLevels` 화이트리스트 맵명 체크(PIE 접두사 제거) → `TActorIterator` 중복 가드 → `Z=-5000` 지하 스폰. `Deinitialize`에서 자체 스폰분만 Destroy.
- `UOJJ_PortraitSettings` (UDeveloperSettings, config=Game): Project Settings ▸ Game ▸ "OJJ Portrait Capture"에 `AutoSpawnLevels`/`PortraitCaptureClass`/`SpawnZ` 노출 — 코드 수정 없이 레벨 추가.
- `AOJJ_PortraitCapture` 생성자: `RT_RobotPortrait` 기본 로드(자동 스폰 시 RT 자동 연결).

## 이슈 목록

### 🟠 Major — 데디케이티드 서버 미제외
- **위치**: `Source/Wanted_Factory/Private/OJJ_PortraitCaptureSubsystem.cpp:15`
- **내용**: `IsGameWorld()`는 데디 서버 월드에서도 true → 서버가 렌더 없이 SceneCapture 액터를 스폰, 메시/RT 에셋 로드·캡처 비용 낭비.
- **영향**: 서버 자원 낭비(기능 결함은 아님, 시각 효과라 서버엔 불필요).
- **처리**: **`NM_DedicatedServer` 가드 추가 완료** — `IsGameWorld` 직후 early return.

### 🟡 Minor — 화이트리스트는 persistent 맵명 전용
- **위치**: `OJJ_PortraitCaptureSubsystem.cpp:27` 부근
- **내용**: `GetMapName()`은 persistent 맵명만 반환 → 스트리밍 서브레벨/World Partition 셀명과는 매칭 안 됨.
- **처리**: **주석으로 명시 완료** (persistent 레벨명 전용). 현재 인게임 레벨이 persistent라 문제 없음.

### 🟡 Minor — SpawnZ 맵 의존성
- **위치**: `OJJ_PortraitCaptureSubsystem.cpp:49` 부근
- **내용**: `Z=-5000` 고정 + AlwaysSpawn → 해당 Z에 콘텐츠 있는 맵에서 겹침 가능.
- **처리**: `SpawnZ`는 이미 `UOJJ_PortraitSettings`에 노출(설정 가능) → 추가 조치 불필요. AlwaysSpawn이라 블로킹 없음.
