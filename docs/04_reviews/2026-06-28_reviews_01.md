# 코드 리뷰 — 평평 램프 건물 허용 (경사 램프는 거부 유지)

- 날짜: 2026-06-28
- 리뷰 방식: codex(GPT) 교차검증
- 영역: OJJ (OJJ_RampFoundation / OJJ_Grid)

## 변경 요약

같은 높이 평탄 파운데이션 2개 사이의 **평평 램프(상승 0 = 평지 브리지)** 위에 건물 배치를 허용. 경사 램프는 거부 유지(버그 b).

- 이전 버그b 수정이 `OJJ_GetUniformSurfaceZ`에서 **모든 램프 셀을 거부**(`bAnyRampCell→return false`)해 평평 램프 위에도 건물이 막힘.
- 평평 램프는 쐐기 미생성(Rise<1) → Deck QueryOnly 평탄 충돌 + 균일 SurfaceZ라 평탄 파운데이션과 동일 → 허용해도 안전.
- 수정:
  1. `AOJJ_RampFoundation::OJJ_IsFlatRamp() const { return PlacedRiseSteps == 0; }` (getter 신설).
  2. `OJJ_GetUniformSurfaceZ` 셀 루프: `Cast<AOJJ_RampFoundation>` 후 **`!OJJ_IsFlatRamp()`일 때만** `bAnyRampCell=true` → 경사 램프만 거부, 평평은 통과.
  3. (codex) `ApplySaveState`도 `PlacedRiseSteps = FMath::Max(0, InRiseSteps)` 클램프(NotifyFitResult와 통일).

## 이슈 목록

### 🟠 Major(엣지) — ApplySaveState PlacedRiseSteps 클램프 누락 (수정 완료)
- 위치: `OJJ_RampFoundation.cpp:395` `ApplySaveState`
- 내용: `NotifyFitResult`는 `Max(0, RiseSteps)`로 클램프하나 `ApplySaveState`는 `InRiseSteps` 그대로 대입 → 비정상 세이브값(음수)이면 `OJJ_IsFlatRamp(==0)` 판정이 로드 경로에서 신뢰 불가.
- 영향: 정상 세이브(신규/정상 로드)엔 무영향. 비정상 데이터 내구성 결함.
- 조치: `FMath::Max(0, InRiseSteps)` 클램프 추가. **적용함.**

### ✅ codex 교차검증 — 나머지 정상 (4/5)
- 평평 셀 균일 SurfaceZ/높이 정합: `OJJ_BuildPerCellSurfaceZ`가 Rise<1서 false → 단일값 `BaseSurfaceZ` 경로(평판과 동일) → 묻힘/뜸 없음.
- 경사 램프 거부 회귀 0: `!IsFlatRamp()` 통과해야 거부 → `PlacedRiseSteps>0`은 기존대로 거부.
- 경로 일관성: 머신/고스트/직배치는 `OJJ_GetUniformSurfaceZ` 경유 → 한 게이트로 일관 허용. 파이프는 별도 `OJJ_GetPipeCellSurfaceZ`(별건), `:417 bRampBoundary`는 컨베이어 땅↔램프 경계 ΔZ 판별(별건).
- Cast null 안전(`RampCell && !...` 단락).
