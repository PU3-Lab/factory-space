- **날짜**: 2026-06-28

- **대상**: `AOJJ_PortraitCapture` 캡처 파이프라인 (커밋 `7e8ffc3` 이후 working 변경 포함)
- **리뷰 방식**: Codex(codex:rescue) 교차 리뷰 + 엔진 소스 검증
- **담당**: OJJ (오재준)

## 변경 요약

대화 패널 포트레이트에 idle 도는 로봇을 실시간 표시하기 위한 SceneCapture 파이프라인.

- `AOJJ_PortraitCapture` (C++): SceneRoot 아래 RobotMesh(단일노드 idle) + KeyLight/FillLight(PointLight) + SpringArm + SceneCaptureComponent2D(ShowOnlyActors=self). `BeginPlay`에서 메시 바운드 기반 자동 프레이밍(상반신 중앙) + RT 연결 + idle 재생.
- 배경 알파 투명: `SCS_SceneColorHDR` + ShowFlags 환경광 차단(Atmosphere/Fog/Sky 등) + UI 머티리얼 `M_Portrait_UI`의 `1-Alpha`로 반전.
- 산출물: `RT_RobotPortrait`(512×512 RGBA8), `M_Portrait_UI`, 셋업 스크립트 2종.

## 이슈 목록

- **위치**: `Source/Wanted_Factory/Private/OJJ_PortraitCapture.cpp:84`
- **내용**: 대화 패널이 닫혀 있어도 512×512 SceneCapture가 매 프레임 렌더링되어 상시 GPU 비용 발생.
