# 재리뷰(2차): 금지어 필터 회귀 및 후속 조치 검증

- 날짜: 2026-06-15
- 리뷰 대상: [`docs/04_reviews/2026-06-15_reviews_02.md`](2026-06-15_reviews_02.md)에 "[조치 완료]"로 표기된 M3·m4·m1의 실제 코드 검증
- 성격: 구현 후 재검증 (브랜치 `feat/material-name-rarity-state`)
- 검증 방법: 코드 정독 + 실제 함수 실행값 확인 + 테스트 스위트 실행(64개 통과)

## 변경 요약

2차 리뷰(reviews_02)에서 제기한 3개 지적(M3 금지어 필터 회귀, m4 테스트 공백, m1 프롬프트 더미 가이드)에 대한 조치가 코드에 반영됐다. 이번 라운드는 **세 건 모두 정확히 해결**되었으며 신규 회귀는 발견되지 않았다.

## 검증 결과

### ✅ M3 (금지어 필터 회귀) — 해결 확인

- 위치: `result_validator.py:46-47`, `result_validator.py:68-69`
- 반영: `\b` 대신 `r"(?<![A-Za-z])" + re.escape(term) + r"(?![A-Za-z])"` 룩어라운드로 교체(권고안과 동일, `re.escape`까지 포함).
- 실제 실행 검증:
  | 입력 | 결과 | 판정 |
  |------|------|------|
  | `_sanitize_id_hint("test_metal")` | `alloy_metal` | ✅ 정화 |
  | `_sanitize_id_hint("dummy_alloy")` | `alloy_alloy` | ✅ 정화 |
  | `_sanitize_name("합금test정")` | `합금합금정` | ✅ 정화 |
  | `_sanitize_name("철test합금")` | `철합금합금` | ✅ 정화 |
  | `_sanitize_name("Latest Protest")` | `Latest Protest` | ✅ 보존 |
  | `_sanitize_id_hint("latest_protest")` | `latest_protest` | ✅ 보존 |
- 언더스코어 결합·한글 인접 케이스 정화와 영어 단어 내부 보존이 동시에 달성됨.

### ✅ m4 (회귀 테스트 공백) — 해결 확인

- 위치: `test_result_validator.py:112-122`
- 반영: `test_sanitize_forbidden_keywords_on_boundaries` 추가. `dummy_alloy → alloy_alloy`, `철test합금 → 철합금합금`을 단언하여 M3 회귀를 직접 가드. 스위트가 63 → 64개로 증가하고 전부 통과.

### ✅ m1 (프롬프트 더미 가이드) — 해결 확인

- 위치: `proposal_generator.py`(프롬프트), `schemas.py:49-51`
- 반영: 프롬프트 JSON 템플릿에서 `properties`/`category`/`rarity` 필드와 더미 주의 문구를 **완전히 제거**(현재 템플릿은 `id_hint`/`name`/`description`/`risks`/`usage`/`next_recipe_candidates`/`visual_prompt`만 요청). `MaterialProposalResult`에 `category="alloy"`, `state="solid"`, `rarity="common"` 기본값을 부여해 LLM이 해당 필드를 생성하지 않아도 파싱됨. 2차 리뷰 권고대로 "추가 지시"가 아닌 "필드 제거 + 스키마 기본값"으로 정정됨.

### ⚪ Nit

**n3. 변경 사항 미커밋 상태**
- 내용: `result_validator.py`, `proposal_generator.py`, `schemas.py`, `test_result_validator.py`가 워킹트리에 수정(M)으로만 존재하고 아직 커밋되지 않음.
- 제안: 검증이 끝났으므로 커밋 권장.

**n4. fallback 생성자의 명시적 구조화 값**
- 위치: `proposal_generator.py:159-164` (`get_fallback_proposal`)
- 내용: 스키마 기본값이 생겼음에도 fallback이 `category="alloy"`, `rarity="common"`, `properties=...`를 명시 전달. derivation override로 무해하나, 기본값과 중복이라 추후 정리 여지.
