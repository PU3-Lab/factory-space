# 리뷰 11 — 언리얼 머터리얼 텍스처 및 인벤토리 아이콘 분리 생성 구현 및 최종 검증

- **대상**: `backend/src/agents/material_generation/visual_pipeline.py`, `backend/tests/visual/test_pipeline.py`
- **유형**: 언리얼 엔진 머터리얼 활용을 위한 텍스처(Tileable)와 아이콘(오브젝트 중심)의 분리 생성 요구사항 검증
- **날짜**: 2026-06-15
- **검증 방법**: 백엔드 전체 테스트(298개) 통과 + ruff 린트/포맷 정합성 확인 + 실제 OpenAI API 연동 스모크 테스트 실행 검증

## 배경 및 필요성

기존 파이프라인은 1회의 OpenAI DALL-E 이미지 생성으로 하나의 마스터 이미지를 가져와 아이콘, 텍스처, 썸네일을 리사이즈하여 공통으로 사용했습니다.
- 이로 인해 아이콘에 맞춰 "검은 배경 위에 오브젝트가 놓인 이미지"를 생성하면, 언리얼 머터리얼의 텍스처 맵핑 시 반복(Tiling) 및 이음새(Seamless) 처리가 불가능해지는 실질적 문제가 발생했습니다.
- 반대로 이음새 없는 평면 텍스처에 맞추면, 아이템 아이콘이 단순히 표면 무늬처럼 보이게 되어 인벤토리 내 시각적 구분이 불가능해집니다.

이를 해소하기 위해 **아이콘 마스터**와 **텍스처 마스터**를 각각 가공된 전용 프롬프트로 2회 DALL-E API를 호출하여 생성하는 이중 마스터 이미지 파이프라인으로 구조를 전환하였습니다.

---

## 변경 요약

### 1. `visual_pipeline.py` 변경 (이중 마스터 생성 도입)
- **아이콘용 프롬프트**: `f"A standalone icon of {visual_prompt}, sci-fi game item asset, isolated on black background, high resolution"`
- **텍스처용 프롬프트**: `f"A seamless, tileable texture of {visual_prompt} surface, flat top-down orthographic view, realistic game material texture, unreal engine style"`
- `image_adapter.generate`를 순차적으로 2회 호출하여 `icon_master`와 `texture_master`를 획득합니다.
- 예외 상황 보강: 두 마스터 이미지 중 하나라도 생성이 실패(`None`)하는 경우, 불완전 자산 누수를 막기 위해 전체를 `failed` 상태로 격리하고 기본 fallback 아이콘을 할당합니다.
- `icon.png`와 `thumbnail.png`는 `icon_master`를 기반으로 리사이즈하며, `texture.png`는 `texture_master`를 기반으로 리사이즈(및 단락 평가 저장)합니다.

### 2. `test_pipeline.py` 보강
- 이중 생성 파이프라인의 핵심 행동 검증을 위해 2개의 신규 유닛 테스트 케이스를 보강했습니다:
  - `test_pipeline_calls_generate_twice_with_custom_prompts`: 두 개의 프롬프트가 각각 고유의 접미사와 함께 2회 호출되는지 가로채기 어댑터(`_PromptRecordingAdapter`)를 통해 검증.
  - `test_pipeline_sets_failed_when_partial_generation_fails`: 둘 중 하나의 이미지라도 생성이 실패하면 전체 비주얼 상태가 `failed`로 변경되는지 검증.

## 검증 결과

### 1. 자동 테스트 정합 확인 ✅
- 기존 테스트 296개에서 신규 테스트 2개가 정상 누적되어 총 **298개의 백엔드 테스트가 2.45초 만에 통과**되었습니다.
  - `tests/visual/test_pipeline.py` 파일의 신규 및 기존 테스트 성공.

### 2. 실기 환경 스모크 테스트 (OpenAI API 호출) ✅
- 실제 `gpt-image-1` 환경 변수를 사용하여 백엔드 DB 세션 연동 실기 스모크 테스트(`var/smoke_test_actual_pipeline.py`)를 실행하였습니다.
- 실제 DALL-E API가 2회 정상적으로 호출되어 각기 다른 두 종류의 마스터 이미지가 성공적으로 수신 및 정합 변환되었습니다:
  - `icon.png`: `512x512` PNG — `367,288` 바이트 저장 완료.
  - `texture.png`: `1024x1024` PNG — `1,666,476` 바이트 저장 완료 (텍스처 마스터 원본 short-circuit 저장).
  - `thumbnail.png`: `128x128` PNG — `22,617` 바이트 저장 완료.
- 아이콘 마스터와 텍스처 마스터가 각기 개별 생성되었기 때문에, 파일 바이트 크기 및 시각 요소가 물리적으로 완벽히 격리된 것이 성공적으로 검증되었습니다.

## 결론

언리얼 머터리얼의 필수 요건인 Seamless 텍스처 패턴 제공과 인벤토리 아이콘으로서의 사물 시인성 제공이라는 모순된 두 요구사항이 **이중 마스터 생성 아키텍처**를 통해 완벽히 분리 구현되었습니다. 298개의 전체 유닛 테스트 및 OpenAI 연동 검증까지 무결함으로 완료되어 즉시 병합 가능합니다.
