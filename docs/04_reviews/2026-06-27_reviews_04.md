# 코드 리뷰 — #7 버그 b: 램프 셀 위 컨베이어/배치물 묻힘·허공

- 날짜: 2026-06-27
- 리뷰 방식: codex(GPT) 교차검증 + 호출처 분석
- 영역: OJJ (OJJ_Grid)

## 변경 요약

램프(경사) 셀 위에서 **플레이어는 통과(충돌=쐐기 convex, 경사 아래 빈공간 미포함)** 하는데 **컨베이어/배치물은 깔리는(배치=셀 장부 SurfaceZ만 검사)** 불일치 수정.

- 원인: `OJJ_GetUniformSurfaceZ`가 셀 장부 SurfaceZ만 보고 균일성 판정 → 특히 **1×1 풋프린트는 자명 통과(F3.10 b②)** → 램프 셀 위 1칸 컨베이어가 장부 Z(계단/Z_low)에 앉아 쐐기에 묻히거나 허공.
- 수정: `OJJ_GetUniformSurfaceZ` 루프에서 각 셀이 램프인지 `Cast<AOJJ_RampFoundation>(GetFoundationAtCell(Cell))`로 검사(`bAnyRampCell`, `bFirst` continue 앞에 배치해 첫 셀 포함). 루프 후 `(bOnFoundation && bAnyRampCell)`이면 `return false`. 평탄 Foundation은 `bAnyRampCell=false`라 무영향.

## 호출처 영향 (codex 검증 — 전부 안전·의도대로)
- `:710` `OJJ_CollectConveyorReservedCells`: 램프 false → `OJJ_ValidateConveyorSlopePath`(:713) 슬로프 경로로 라우팅(컨베이어 의도 동작). 파이프는 `bAllowWaterCells=true`라 `bConveyorPath` 제외 → 무영향.
- `:4369` `OJJ_TryPlaceConveyor`: 램프 false → 슬로프/비주얼Z 분기(:4375) + `OJJ_ValidateConveyorSlopePath`(:4384) 재검증 + 노드별 Z 주입(램프 비주얼). 의도된 컨베이어-온-램프 경로.
- `:4589` `CanPlaceMachine`: 램프 false → 풋프린트 직접 거부(:4591). 1×1·혼합 머신이 램프 셀에 안 깔림(의도).
- `:1097` `GetMachinePlacementLocation` / `:5084` `OJJ_ShowGhostForMachine`: 상위 게이트(`CanPlaceMachine`)가 먼저 거부 → 안전. 고스트 valid/invalid 상태 정상 전파.

## 이슈 목록
### ✅ codex 교차검증 — 실제 버그 없음
- 첫 셀 램프 감지 누락 없음(`bAnyRampCell` 집계가 `bFirst` continue 앞).
- 평탄 Foundation 1×1/다셀 회귀 없음.
- `GetFoundationAtCell` null 반환 → null-safe `Cast` → 크래시 위험 없음.
- 지형(비-Foundation) 경로 무영향(`bOnFoundation` 게이트).
- 혼합 평탄+램프 같은Z 풋프린트도 의도대로 거부(슬로프 경로/머신 거부로 라우팅).
