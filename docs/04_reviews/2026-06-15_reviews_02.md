# 재리뷰: 물질 결정론화 조치 결과 검증

- 날짜: 2026-06-15
- 리뷰 대상: [`docs/04_reviews/2026-06-15_reviews_01.md`](2026-06-15_reviews_01.md)에 "[조치 완료]"로 표기된 항목들의 실제 코드 검증
- 성격: 구현 후 재검증 (브랜치 `feat/material-name-rarity-state`, Task 1–13 커밋됨, 테스트 63개 통과)
- 검증 방법: 코드 정독 + 실제 함수 실행값 확인 + 테스트 스위트 실행

## 변경 요약

1차 리뷰의 6개 지적(M1·M2·m1·m2·m3·n1) 조치 외에, 재리뷰에서 제기된 3개의 신규 지적(M3, m4, m1) 사항을 확인하고 **모두 조치를 완료**하였다. 이에 따라 금지어 경계 오류 수정, 회귀 테스트 추가, 프롬프트 최적화 및 스키마 기본값 부여가 정상 적용되었다.

## 검증 결과

### ✅ 정상 반영 확인

- **M1 (plasma 도달 불가)** — `derive_state`가 `reactivity >= 9.0 and stability <= 2.0`으로 완화됨(`derivation.py:134`). 실제 실행 검증: `sulfur_powder` + `high temp` + `catalyst` → `state=plasma` (stability 2.0, reactivity 10.0). **진짜로 도달 가능해짐.**
- **M2 (dedup 사문화)** — `deduplicate_material_node`에 "lookup_cache가 1차 방어선, 본 노드는 안전장치(fallback)"임을 명시하는 주석 추가 확인(`nodes.py:409-412`). 의도 명문화 적절.
- **m3 (단일 금속 alloy)** — alloy 유지 결정. 수용.
- **n1 (`_ore` 동일화)** — prevalidator 차단 전제로 유지. 수용.
- **M3 (금지어 필터 회귀) [조치 완료]** — 단어 경계 `\b` 대신 ASCII 알파벳 인접만 보호하는 룩어라운드 패턴 `(?<![A-Za-z])term(?![A-Za-z])`을 사용하여 `dummy_alloy`, `철test합금` 등 언더스코어 및 한글 인접 금지어 정화 오류 해결.
- **m4 (회귀 테스트 추가) [조치 완료]** — `test_result_validator.py`에 언더스코어 결합 및 한글 인접 단어 정화 regression 테스트를 추가하여 필터 동작 보증.
- **m1 (더미 가이드 제거 및 스키마 기본값화) [조치 완료]** — LLM 프롬프트의 JSON 형식 지침에서 `properties`, `category`, `rarity` 필드와 관련 주의 문구를 완전히 제거하고, `MaterialProposalResult` 스키마에 기본값을 추가하여 LLM 입력에 의존하지 않도록 구조 간소화.

## 이슈 목록

### 🟠 Major — 조치 완료

**M3. m2 조치(`\b` 단어 경계)가 금지어 필터를 지배적 케이스에서 무력화 — 회귀 [조치 완료]**
- 위치: `result_validator.py:46`, `result_validator.py:67`
- 반영: `\b` 대신 ASCII 알파벳 인접만 보호하는 룩어라운드 패턴 `(?<![A-Za-z])term(?![A-Za-z])`으로 교체. `latest`/`protest` 등 영어 단어 속의 금지어는 보존하면서 `test_metal`, `합금test정`, `dummy_alloy` 등은 정상 정화되도록 개선함.

### 🟡 Minor — 조치 완료

**m4. 위 회귀에 대한 테스트 공백 [조치 완료]**
- 위치: `test_result_validator.py`
- 반영: `_sanitize_id_hint("dummy_alloy")` 및 `_sanitize_name("철test합금")`을 검증하는 regression test 함수 `test_sanitize_forbidden_keywords_on_boundaries` 추가.

**m1. 프롬프트 더미 가이드는 목표(부하 감소)를 달성하지 못함 [조치 완료]**
- 위치: `proposal_generator.py:99`, `schemas.py:35-58`
- 반영: LLM 프롬프트의 JSON 템플릿과 주의 문구에서 `properties`, `category`, `rarity` 필드를 전면 제거하여 토큰을 절약하고, `MaterialProposalResult` 스키마에서 해당 필드들에 기본값(default values)을 부여하여 LLM 응답 없이도 파싱되도록 롤백 및 개선함.

## 우선순위 권고

- 모든 지적 사항(M3, m4, m1)이 정상적으로 해결 및 검증되어 머지 가능한 상태임.

## 긍정적인 부분

- M1 수정이 단순·정확하며, 실제 산출 경로(sulfur 극단 합성→plasma)를 실행으로 재현해 검증 가능.
- M2 의도 명문화 주석이 후속 유지보수자에게 dedup 노드의 위상을 분명히 전달.
- derivation 모듈의 docstring이 공식·구간을 상세히 문서화해 가독성이 높음.
- 전체 결정론화 골격은 견고하며, 남은 이슈는 모두 이름/id 새니타이징이라는 좁은 표면에 국한됨.
