# 재리뷰(3차): Nit 후속 조치(n3 커밋 / n4 fallback 정리) 검증

- 날짜: 2026-06-15
- 리뷰 대상: [`docs/04_reviews/2026-06-15_reviews_03.md`](2026-06-15_reviews_03.md)에 "[조치 완료]"로 표기된 n3·n4의 실제 코드 검증
- 성격: 구현 후 재검증 (브랜치 `feat/material-name-rarity-state`)
- 검증 방법: 코드 정독 + 실제 함수 실행 + 테스트 스위트 실행(64개 통과)

## 변경 요약

3차 리뷰(reviews_03)의 Nit 2건(n3 미커밋, n4 fallback 중복 값)에 대한 조치가 반영됐다. 두 건 모두 처리됐고 테스트는 통과하나, n4 구현 과정에서 `MaterialProperties` 필드에 `0.0` 기본값이 도입되어 **부수효과 1건**을 새로 기록한다(현 플로우에서 무해).

## 검증 결과

### ✅ n3 (미커밋) — 해결 확인

- 커밋 `fee1942 feat(material_generation): 물질 결정론화 2차/3차 재리뷰 지적사항 조치 완료` 존재. `git status` 클린(material_generation 변경 없음).

### ✅ n4 (fallback 중복 값) — 해결 확인

- 위치: `proposal_generator.py:get_fallback_proposal`
- 반영: fallback 생성자에서 `category`/`rarity`/`properties` 명시 인자를 제거. 실제 실행 시 스키마 기본값으로 채워지며 예외 없이 동작(`get_fallback_proposal([iron_ingot])` → name="Iron 합금", category="alloy", rarity="common", state="solid").

## 이슈 목록

신규 Blocker/Major/Minor 없음.

### ⚪ Nit

**n5(신규). `MaterialProperties` 필드 0.0 기본값 도입 → standalone fallback이 전부 0.0**
- 위치: `schemas.py:38-41`(`strength/conductivity/stability/reactivity: float = 0.0`), `proposal_generator.py:get_fallback_proposal`
- 내용: n4에서 `properties`를 생략 가능하게 만들기 위해 `MaterialProperties`의 4개 필드에 `0.0` 기본값을 부여하고, `MaterialProposalResult.properties = Field(default_factory=MaterialProperties)`로 변경했다. 그 결과 `get_fallback_proposal`은 이제 속성이 전부 `0.0`인 물질을 반환한다(기존엔 5/5/5/2). 또한 Pydantic이 속성 누락을 더 이상 검증 오류로 잡지 못한다.
- 영향: **현재 플로우에서는 무해.** fallback 제안의 속성은 `validate_result_node`/`llm_propose_node`의 `_apply_derived`로 항상 결정론 값으로 덮어써진 뒤 저장·응답되므로, `0.0`이 영속되거나 노출되지 않는다.
- 리스크(잠재): "derivation override가 항상 선행된다"는 불변식에 의존한다. 향후 `get_fallback_proposal`을 override 없이 직접 쓰는 경로가 생기면 전스탯 0짜리 물질이 새어 나갈 수 있다.
- 제안(선택): (a) `MaterialProperties` 기본값을 중립값(5.0)으로 두거나, (b) `get_fallback_proposal`에서 derivation을 직접 호출해 안전한 속성을 채우거나, (c) 불변식을 주석/테스트로 고정. 급하지 않음.

## 우선순위 권고

- n3·n4 해결·검증되어 **머지 가능 상태 유지.**
- n5는 무해한 잠재 항목으로 후속 정리 대상(머지 차단 아님).

## 긍정적인 부분

- 변경이 커밋되어 작업 트리가 깨끗하고, fallback 단순화로 중복 코드가 제거됨.
- 4회 누적 리뷰에서 제기된 Blocker/Major/Minor가 모두 소진되고, 잔여는 무해한 Nit 1건뿐 — 결정론화 기능이 머지 기준을 충족.
