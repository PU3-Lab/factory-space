# 코드 리뷰 — #B 평탄 파운데이션 지형 묻힘 거부 (호버/타일색/배치 정합, 램프 예외)

- 날짜: 2026-06-27
- 리뷰 방식: 조사(SnapLift 전제 정정) → codex(GPT) 교차검증
- 영역: OJJ (OJJ_Grid / OJJ_BuildController)

## 변경 요약

평탄 파운데이션(AOJJ_Foundation) 상면 Z가 셀 지형 Z보다 낮으면(일부 셀이라도) 배치 거부. 램프는 면제(바닥 연결). 호버/타일색/배치 3경로가 동일 상면 Z로 정합.

- **상면 Z 단일원 헬퍼** `OJJ_ComputeFoundationTopZ(CDO, Origin, EffSize, RotSteps)` = `GetFoundationPlacementLocation().Z + OJJ_ComputeSnapLift + GetFoundationHeightLiftZ + Thickness` — 배치 `BaseSurfaceZ` 산식과 동일.
- **CanPlaceFoundation** 시그니처 확장: `(..., float FoundationTopZ=0.0f, bool bRejectBuried=false)`. `bRejectBuried`면 셀 순회 중 `OJJ_GetRawTerrainSurfaceZ(Cell) > FoundationTopZ + KINDA_SMALL_NUMBER` 면 `Buried++` → 거부(flush 허용). 기본 인자라 타 호출처 무영향.
- **3경로 전달**: 호버 고스트(평탄=`bRejectBuried=true`) / 타일색(`OJJ_UpdateFoundationHoverPreview`에 TopZ/플래그 추가, `!bRampFoundationSelected`) / 배치(`OJJ_TryPlaceFoundationInternal`에서 `Cast<AOJJ_RampFoundation>==nullptr`로 평탄만, `FoundationTopZ=SurfaceZForCell(Origin)`).
- **램프 예외**: 호버 else(램프) 분기 기본 인자(false), 배치 Cast 면제.

## 전제 정정 (조사)
- 기존 "평탄 SnapLift=0, 그리드 평면 고정"은 **부정확**. base `OJJ_ComputeSnapLift`: 이웃 접촉 시 이웃 Z 상속 / 고립 시 풋프린트 max 지형 스냅. → **진짜 묻힘은 낮은 이웃 상속을 높은 지형으로 확장할 때**. 따라서 묻힘 비교는 그리드 평면이 아니라 **실제 스냅된 상면 Z** 기준이어야 정확(헬퍼가 이를 단일원으로).

## 이슈 목록
### ✅ codex 교차검증 — 실제 버그 없음 (7/7)
1. 호버 TopZ == 배치 BaseSurfaceZ (동일 산식, RotSteps=Fit.EffectiveRotationSteps) → 호버=배치 정합.
2. 배치 `FoundationTopZ=SurfaceZForCell(Origin)` — 평탄 균일 = BaseSurfaceZ, Origin 인덱스 안전.
3. 램프 면제 정확(호버 else + 배치 Cast 양쪽).
4. flush 허용(`> +KINDA_SMALL_NUMBER`).
5. 지형 무효 셀(`OJJ_GetRawTerrainSurfaceZ` false) → 묻힘 미판정(안전측).
6. 기존 CanPlaceFoundation 호출처 회귀 0(기본 인자 false).
7. `OJJ_ComputeSnapLift` 비-const CDO 호출 읽기전용 안전, UFUNCTION 리터럴 기본인자(0.0f) UHT 통과.
