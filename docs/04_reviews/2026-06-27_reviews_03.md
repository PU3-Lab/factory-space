# 코드 리뷰 — #5 전선(PowerLine) 설치 미리보기 실제 메시화 (B안)

- 날짜: 2026-06-27
- 리뷰 방식: codex(GPT) 교차검증 + UE 5.7 컴포넌트/머티리얼 API 대조
- 영역: OJJ (OJJ_BuildController) — Chan APowerLine 무수정(sag 공식 복제 + getter 읽기만)

## 변경 요약

전선 설치 드래그 미리보기를 `DrawDebugLine`(개발 전용)에서 **실제 메시(출시 빌드 가시) + 동적 머티리얼 3색**으로 교체.

- `UpdatePowerLinePreview(Hit)`: 앵커↔조준을 실린더 `UStaticMeshComponent` 세그먼트 풀(재사용)로 그림.
  - **색 3단계**(M_Ghost_Preview MID `TintColor`): 노랑=드래그(타겟 없음) / 초록=`CanConnectPowerLineEndpoints` / 빨강=무효 or (시작 Node일 때 거리 > `GetConnectionRadius`).
  - **sag/세그먼트/끝점Z 공식**은 `APowerLine` 룩을 읽어 OJJ에 재구현(`SagDepth=clamp(수평거리×0.035,0,120)`, 세그먼트=`clamp(길이/150,6,24)`, Node −90/Plant −110). Chan 코드 무수정.
- `UpdateMouseHover` PowerLine 분기: `DrawDebugLine` → `UpdatePowerLinePreview(Hit)`.
- 생성자: `/Engine/BasicShapes/Cylinder` + `M_Ghost_Preview` 기본 로드(에디터 재지정 가능).
- 소등: `CancelPowerLineDrag`(취소·커밋·모드전환 공통) + `ExitBuildMode` + `!bHit`(허공) 경로.

## 이슈 목록

### 🟠 Major — 트레이스 미스(허공) 시 미리보기 잔상 (수정 완료)
- 위치: `OJJ_BuildController.cpp` `UpdateMouseHover()` `!bHit` 조기 return 분기
- 내용: `ResolveBuildTraceHit` 실패(커서가 허공) 시 PowerLine 분기 도달 전에 early-return → 드래그 중이면 직전 프레임 세그먼트가 잔존.
- 영향: 커서를 하늘/빈 공간에 두면 전선 미리보기가 멈춘 채 남음.
- 조치: `!bHit` 분기에 `HidePowerLinePreview()` 추가. **적용함.**

### 🟡 Minor — 머티리얼 null 경로의 stale MID 미정리 (수정 완료)
- 위치: `OJJ_BuildController.cpp` `EnsurePowerLinePreviewMID()`
- 내용: `PowerLinePreviewMaterial`이 (에디터에서) 해제되면 기존 `PowerLinePreviewMID`와 세그먼트 `SetMaterial` 오버라이드가 정리되지 않아 낡은 색이 잔류(`SetMaterial` 오버라이드는 명시 해제 전까지 유지).
- 영향: 엣지(런타임엔 생성자 로드라 보통 non-null) — 머티리얼을 비우면 stale 색.
- 조치: null 경로에서 `PowerLinePreviewMID=nullptr` + 세그먼트 `SetMaterial(0,nullptr)`. **적용함.**

### ✅ 정상 확인 항목 (codex + API 대조)
- 세그먼트 풀 재사용(매 프레임 생성/파괴 없음), 남는 세그먼트 `SetVisibility(false)`.
- 독립 씬 컴포넌트(루트 미부착) + `Mobility=Movable` + `SetWorldLocationAndRotation/SetWorldScale3D` 렌더 정상.
- MID 멱등/생명주기(parent 교체 시 재생성, `RF_Transient`).
- 소등 경로 완전성: 커밋(Commit→Cancel 호출)·모드전환(SetPlacementMode→Cancel 호출)·Exit·허공 모두 커버.
- null 가드(StartMachine/Mesh/FactoryManager/MID), 색 판정(getter 읽기·Plant 시작 시 허공 노랑 유지), 엔진 Cylinder 피벗 중앙 가정.

- Chan 영역 무접촉(sag 공식 복제 + `GetConnectionRadius`/`CanConnect` 읽기만)으로 출시 빌드 가시 미리보기 달성.
