# 코드 리뷰 — 빌드모드 L키 작업등 (TPS NightSpotLight 재활용 + 탑다운 하향 SpotLight 신설)

- 날짜: 2026-06-27
- 리뷰 방식: codex(GPT) 교차검증 + UE 5.7 컴포넌트 API 대조
- 영역: OJJ (OJJ_Player / OJJ_BuildCamera)

## 변경 요약

빌드모드에서 L키로 작업등을 토글한다(밤 건물 설치 가시성). 화면 노출이 아니라 실제 SpotLight를 쓰며 밤 분위기를 유지한다.

- **L키 토글**: `BindKey(EKeys::L)` → `ToggleWorkLight()` — `IsInBuildMode()` 가드로 빌드 밖 무동작. `bWorkLightOn` 토글.
- **매 틱 분배** (`UpdateNightSpotLightVisibility`, 단일 진입점):
  - TPS 빌드 + 작업등 → `NightSpotLight` 점등 + 상향(`TPSWorkLightIntensity/Radius`).
  - 밤 일반(빌드 밖/그 외) → 기본값(BeginPlay 캡처) 원복.
  - TopDown 빌드 + 작업등 → `BuildCamera` 하향 `WorkLight` 점등.
- **탑다운 전용 하향광 신설**: `AOJJ_BuildCamera`에 `USpotLightComponent WorkLight`(Camera 부착 → forward=하향), 기본 off, `SetWorkLightEnabled()`로 토글.
- **리셋**: 빌드 해제(None) 시 `bWorkLightOn=false` + BuildCamera 하향광 즉시 off.

## 이슈 목록

### 🟡 Minor — TopDown→TPS 전환 시 하향광 1프레임 잔광 (수정 완료)
- 위치: `frontend/Source/Wanted_Factory/Private/OJJ_Player.cpp` `ApplyBuildModeView()` TPS 전환 브랜치
- 내용: TopDown→TPS 전환 시 `BuildCamera->WorkLight`(월드 스폿)를 즉시 끄지 않아, 다음 틱 `UpdateNightSpotLightVisibility`가 끌 때까지 1프레임 동안 TPS 뷰에 잔광이 보일 수 있음. 즉시 off는 None 브랜치에만 있었음.
- 영향: 1프레임 광량 플래시(경미, 기능 영향 없음).
- 조치: TPS 브랜치에 `BuildCamera->SetWorkLightEnabled(false)` 추가(None 브랜치와 일관). **적용함.**

### ✅ 정상 확인 항목 (codex + API 대조)
- 매 틱 visibility/intensity 덮어쓰기 함정: 작업등 분배를 `UpdateNightSpotLightVisibility` 단일 진입점에 통합 → TPS 작업등/밤 일반 점등이 충돌 없이 정확히 분배.
- BeginPlay 기본값 캡처: `BaseNightLightIntensity/Radius`를 `UpdateNightSpotLightVisibility` 첫 호출 **전에** 캡처 → 생성자값(50/1500) 정확히 보존.
- BuildCamera WorkLight 방향: Camera에 부착 + 상대회전 0 → Camera forward(SpringArm pitch -90, 하향) 상속 → 빌드 영역을 아래로 비춤.
- L키 충돌: C++ BindKey 미사용(빈 키). 핸들러 `IsInBuildMode` 가드로 빌드 밖 무동작.
- null 가드/생명주기: `NightSpotLight`/`BuildCamera`/`BuildController` 전부 null 가드. 토글은 상태 플래그만 변경(라이트 직접 조작은 매 틱 갱신이 전담).

## 긍정적인 부분
- 매 틱 덮어쓰기 함정을 정확히 인지해 단일 진입점에 통합(외부 SetVisibility 무효화 회피).
- 기존 NightSpotLight 최대 재활용(TPS) + 탑다운만 신규 컴포넌트로 최소 추가.
- 노출/포스트프로세스 무접촉 → 밤 분위기·DayNightController와 충돌 없음.
- 라이트 파라미터 전부 튜너블(UPROPERTY)로 노출. 빌드 `Result: Succeeded`(경고 0).
