# Sprint 7 보완 리뷰 결과

## 결론

Sprint 7의 전용 LangGraph 내부 측정 흐름은 구현되어 있었지만, 최초 리뷰 시점에는 공통 WebSocket 파이프라인에서 `operation: "measure"`가 `process_optimizer_v2_graph`로 라우팅되지 않았다. 따라서 직접 graph 테스트는 통과해도 Unreal `/ws/agent` 경로에서는 측정 기능을 사용할 수 없는 상태였다.

이번 보완으로 `measure` 라우팅, 응답 status schema, before 상태 검증, pipeline smoke test를 추가해 Sprint 7 기획의 실사용 경로까지 맞췄다.

## 보완한 내용

| 항목 | 기존 상태 | 보완 후 |
| --- | --- | --- |
| WebSocket 라우팅 | `apply`, `undo`만 v2 graph로 이동 | `measure`도 `process_optimizer_v2_graph`로 이동 |
| 응답 status schema | `measurement_ready`, `measurement_not_ready` 등 일부만 허용 | `record_not_found`, `invalid_factory_state`, `measurement_error`, apply/undo 오류 status까지 허용 |
| before 상태 신뢰성 | `before.state_known = false`여도 측정 결론을 낼 수 있음 | authoritative before state가 없으면 `measurement_not_ready`로 차단 |
| 테스트 범위 | 전용 graph 직접 호출 위주 | `AgentPipeline().run(...)` 기반 measure 라우팅 테스트 추가 |
| 자동 rollback 방지 | degrade 시 `commands: []` 검증 | 유지 |
