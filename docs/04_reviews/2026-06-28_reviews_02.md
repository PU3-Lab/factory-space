# 코드 리뷰 — 단일 배치(머신/파운데이션) 후 손 비우기

- 날짜: 2026-06-28
- 리뷰 방식: codex(GPT) 교차검증
- 영역: OJJ (OJJ_BuildController)

## 변경 요약

머신/파운데이션(단일 칸 배치)을 설치하면 **선택 해제(손 비움)** — 커서 비고 고스트 사라지며, **빌드모드 자체는 유지**. 컨베이어/파이프(드래그)·철거·파워라인은 무수정(연속 유지).

- `OJJ_BuildController.cpp` 두 성공부에 `SetPlacementMode(EOJJ_BuildPlacementMode::None);` 한 줄씩:
  - 머신: `OnLeftClickPressed` 인라인 배치 성공부(quest notify 직후, `CurrentHoverCell` 리셋 뒤).
  - 파운데이션: `PlaceFoundationAtCursor` 성공부(튜토리얼 notify 뒤).
- `None` = Z키(`CancelPlacementShortcut`)가 쓰는 검증된 손비움 상태 — `SetPlacementMode(None)`이 드래그 취소 + 그리드색 갱신 + 호버셀 리셋 + `UpdateMouseHover`(None 분기 고스트 숨김)까지 처리.
- ⚠️ `PlacementMode`(None)와 `BuildViewMode`(TopDown/TPS) 별개 → 빌드모드 유지.

## 이슈 목록
### ✅ codex 교차검증 — 실제 버그 없음 (6/6)
1. quest notify **뒤** 호출 — `GetQuestPlacementTargetId(PlacementMode)` 보존(None 전환 전에 quest target 계산).
2. 성공 시에만 도달 — 실패 경로는 삽입 지점 전 early-return.
3. `SetPlacementMode(None)` 내부(드래그취소→호버리셋→UpdateMouseHover) 안전, 재진입/중복 리셋 문제 없음.
4. 머신 인라인 경로는 함수 끝 — None 이후 `PlacementMode` 재사용 없음.
5. 컨베이어/파이프/전선/철거는 각자 분기 후 return → 두 삽입 지점 미통과(무영향, 연속 유지).
6. `SetPlacementMode` early-return(`==NewMode`) 무관 — 배치 시 `PlacementMode != None`이라 정상 진입.
