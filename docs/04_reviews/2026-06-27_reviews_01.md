# 코드 리뷰 — 자기폭풍 차폐장 돔 내부 Niagara 차폐 (Kill Box)

- 날짜: 2026-06-27
- 대상 커밋: `07dd831` (feat(fx): 자기폭풍 차폐장 돔 내부 Niagara 차폐) + codex 피드백 수정
- 리뷰 방식: codex(GPT) 교차검증 + 엔진 소스(UE 5.7) 대조
- 영역: OJJ (Chan의 PlanetEventManagerSubsystem 무접촉)

## 변경 요약

자기폭풍 중 플레이어에게 가장 가까운 "활성" 차폐장(`AOJJ_ProtectionTower`)의 위치/반경을
`NS_Magnetic`의 User 파라미터(`User.ShieldCenter`[Vec3] / `User.ShieldRadius`[float])에 주입.
Niagara 측 Particle Update 스크래치가 `distance(Position, ShieldCenter) < ShieldRadius`(且 Radius>0)
파티클을 Kill → 돔 내부가 깨끗하고 돔 밖은 폭풍 유지. 활성 돔 없으면 반경 0으로 무력화.

- `NS_Magnetic.uasset`: World Space sim + User 파라미터 2개 + Particle Update Scratch Kill (에디터 작업)
- `OJJ_DayNightController.h/.cpp`: `UpdateStormShieldParams()` 주입 로직
  - Tick에서 0.25초 스로틀(가드 무관하게 갱신, 폭풍 없으면 내부 즉시 반환)
  - `HandlePlanetEventStarted`에서 폭풍 시작 즉시 1회 주입(첫 틱 전 깜빡임 방지)
  - `TActorIterator<AOJJ_ProtectionTower>` 자체 순회로 최단거리 활성 차폐장 선택

## 이슈 목록

### 🟠 Major — 자동소멸 Niagara 컴포넌트 생명주기 가드 누락 (수정 완료)
- 위치: `frontend/Source/Wanted_Factory/Private/OJJ_DayNightController.cpp` `UpdateStormShieldParams()` 진입부
- 내용: 월드 스폰 경로(`SpawnSystemAtLocation(..., bAutoDestroy=true, ...)`)에서 시스템 완료 시
  컴포넌트가 PendingKill 되어도 raw 포인터는 GC 전까지 non-null로 남는다. 기존 `!ActiveEventNiagaraComponent`
  검사만으로는 stale 포인터에 `SetVariableVec3/Float`를 호출할 위험.
- 영향: 기본은 attach 모드(`bAutoDestroy=false`)라 실사용 리스크는 낮으나, 월드 경로의 잠재 크래시.
- 제안/조치: `if (!IsValid(ActiveEventNiagaraComponent) || ...)`로 변경 — PendingKill까지 방어. **적용함.**

### 🟡 Minor — 스로틀 누적 오차(드리프트) (수정 완료)
- 위치: `frontend/Source/Wanted_Factory/Private/OJJ_DayNightController.cpp` Tick 스로틀 블록
- 내용: accumulator를 `0.0f`로 리셋해 임계 초과분 DeltaTime을 버림 → 프레임 시간이 0.25초를
  정확히 나누지 못하면 갱신 주기가 지속적으로 늦어지는 누적 오차.
- 영향: 갱신 간격이 의도(0.25s)보다 미세하게 길어짐(연출 영향 경미).
- 제안/조치: `ShieldParamUpdateAccumulator -= ShieldParamUpdateInterval`로 잔여 보존. **적용함.**

### ✅ 정상 확인 항목
- 최단거리 활성 차폐장 선택: `NearestShield=nullptr`/`NearestDistSq=Max` 초기화 + 타입 제한 순회 +
  `IsShieldActive()` 필터 + `DistSq < NearestDistSq` 갱신 → 정확.
- User 파라미터 이름: `"User.ShieldCenter"` / `"User.ShieldRadius"` 풀네임. UE 5.7
  `NiagaraComponent.h:493,520`은 `FName`을 그대로 사용, `FNiagaraUserRedirectionParameterStore::IsUserParameter`가
  `"User."` 접두를 유저 파라미터로 판정 → 매칭 정확.
- 활성 돔 없음 → `ShieldRadius=0` 주입으로 Kill 무력화(스크래치 가드와 정합).

## 긍정적인 부분
- Chan 서브시스템(`RegisteredShields`)을 건드리지 않고 OJJ 액터 자체 순회로 영역 경계 준수.
- 가드(`bEnabled`/`SunLight`)와 분리해 오설정에도 Kill Box 동작. 폭풍 시작 즉시 주입으로 깜빡임 차단.
- `GetShieldRadius()` 재사용으로 돔 비주얼 스케일과 자동 정합(하드코딩 없음).
- 빌드 2회(초기/수정 후) 모두 `Result: Succeeded`, 경고 0. PIE에서 "돔 안 구멍 + 밖 폭풍" 확인.
