## 2. 남은 사항

### 🟡 Major급 가시성 / 코드-severity Minor — 레벨 게이트의 "설계 불변식" (M-1 재부상, 정리됨)

- 위치: `agents/quest_generator/rule_generator.py:52-54`
- 맥락: 게이트가 이제 면제 없이 `min_level(item) > factory_level → skip`으로 작동한다. 이는 **고티어 아이템이 메인 퀘스트의 직접 목표여도** 레벨 미달 시 지원 퀘스트를 생성하지 않음을 의미한다.
- 트레이드오프(설계 진동의 정체):
  - 1차: 면제 없음 → 데드락 우려(M-1)
  - 2차: 면제 추가 → 게이트 무력화(R-1)
  - 3차(현재): 면제 제거 → 게이트는 작동, 단 M-1 우려가 다시 유효
- 실제 위험도: **하드 블록은 아니다.** 지원 퀘스트는 "보조"이고, 플레이어는 해당 아이템을 직접 수집/생산해 메인 퀘스트를 진행할 수 있다. 다만 "가장 도움이 필요한 고티어 목표에서 지원 시스템이 침묵"하는 상황은 남는다.
- 핵심: 현재 코드는 다음 **암묵적 불변식**을 전제로만 올바르다 — **"레벨 N의 메인 퀘스트는 `min_level ≤ N`인 아이템만 요구한다."** 메인 퀘스트 콘텐츠(클라 제공)와 `game_data._ITEM_MIN_LEVELS`는 별개 출처라, 둘이 어긋나면 지원이 침묵한다.
- 제안(택1, 코드 변경 불요할 수도):
  - (a) **불변식을 콘텐츠 규칙으로 보장**: 메인 퀘스트 생성/배치 시 `min_level ≤ factory_level` 아이템만 요구. → 현재 코드 그대로 정답. 계획서/문서에 불변식 명시.
  - (b) 보장 불가하면, 면제를 **"이번 이슈를 유발한 그 메인 목표"에 한정**(2차의 blanket 면제처럼 전체 무력화되지 않도록)하거나, 게이트 미달 시 **중간재 대체 목표**로 폴백.
  - 어느 쪽이든 게이트로 후보가 전부 막힌 경우는 로깅해 관측 가능하게.

### 🟡 Minor — R-4 공유 refiner 싱글톤 동시성 (유지)

- 위치: `agents/quest_generator/compose_service.py:31` `default_refiner`(모듈 싱글톤)
- 내용: REST(스레드풀)·WS(`asyncio.to_thread`)가 동일 refiner/LLM 어댑터를 동시 호출 가능. 어댑터가 thread-safe하지 않으면 경합 위험. 어댑터 동시성 보장 여부 확인 권장.
